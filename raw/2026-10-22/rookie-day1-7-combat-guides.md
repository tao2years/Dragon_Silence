## 七日成长正文

- URL: https://www.dragonheir.info/article/570
- Published: 2025-06-26

### Day 1推荐顺序

1. 用赠送英雄推主线到当日尽头并取得Furywood Claws；首日等级还无法装备；
2. 打地精，逐层吃首通，直到无法继续；
3. 打剧毒墓穴，逐层吃首通，直到无法继续；
4. 回地精重试；
5. 装备已无法继续提升后再去时空涡流打海王；
6. 不在低收益地精层反复烧体力；正文建议能稳定刷Lv.6再重复，否则做探索/进阶任务。

### Day 2–3

- 得到Garius后可替换Horrus；
- 手套和衣服开放后先刷套装，再回地精；
- 地精可用Ladehlia替换Estella提高输出；
- Furywood Claws可交给主C；
- 历史正文称当时等级上限59；仅作版本样本。

### Day 4–7

- Day4历史节点：60级、金装、正向符文；先主C与主坦完整套装；
- Day5–6：先主C/主坦天赋4，火毒、冰暗、电光可成对刷；全队补正向符文；
- Day7：全队天赋4、全员装备后再细调主坦/主C属性。

## 地精1–12

- URL: https://www.dragonheir.info/article/587
- Stable source ID: `WIKI-022`

正文对1–6层的可恢复信息：

- 六波小怪；用两名英雄的威能清第一波、剩余三名清第二波，如此轮转；
- 沃雷什先开威能给减益，西格莉德后开范围追击；
- 拉瓦先手后，维迪米尔与罗薇娜再开技能；
- 次日可装备Furywood Claws提高地精伤害，之后换更好的紫装。

因此可复原的历史五人模板是：`拉瓦 + 维迪米尔 + 罗薇娜 + 沃雷什 + 西格莉德`。具体中文译名和370赠送情况待客户端核对。

## 装备本分段策略

- URL: https://www.dragonheir.info/article/585
- Stable source ID: `WIKI-023`

- 剧毒墓穴：群攻、降攻、减伤/受击回复；击杀小怪造成真伤，带减益的小怪更少协击。1–8生存低；9–14需群体降攻，坦不够则双奶或减伤+奶。
- 诅咒墓穴：禁增益/驱散、护盾、降攻；1–8先阻止Boss攻击增益；9–14在Boss威能时开治疗减伤。
- 腐烂墓穴：免疫、净化、减伤和分散站位；不必要的减益会强化Boss机制。
- 异教遗迹：眩晕、减疗、免疫；Boss会复活小怪并隐身，小怪存活给Boss持续治疗。
- 古战场：禁增益、降命中、降攻；Boss会清除我方增益并永久加攻，有剑盾姿态切换。

## 三类天赋本1–6

### Wildfire / 火毒素材本

- URL: https://www.dragonheir.info/article/589
- Stable source ID: `WIKI-024`

副本克制火/毒。用Catherine在Boss威能前开全体减益免疫；Garius可自净化。正文以Ladehlia+Isitarian召唤物清场，Acilia可替Catherine。第二阶段留Catherine威能，进第三阶段前开以防燃烧。

### Resplendence / 电光素材本

- URL: https://www.dragonheir.info/article/590
- Stable source ID: `WIKI-025`

副本克制光/电。用Estella+Heksandra双治疗加速机制，Ladehlia+Sigrid清幼龙；Boss第二小阶段前先关自动，进入后再集中开。Frurbath和双辅助用治疗促使Boss变龙，幼龙带减益后由Sigrid手动威能清场并回能。

### Permafrost / 冰暗素材本

- URL: https://www.dragonheir.info/article/591
- Stable source ID: `WIKI-026`

副本克制冰/暗。用Acilia或免费Catherine处理全队控制/减益；Boss施加Exhaustion或降攻时不要开威能，等第二技能后再开；Boss威能时用免疫。无高配无畏时可用Shook+Vani+Catherine，Shook负责驱散护盾。

## 主线卡点

### The Blasphemous

- URL: https://www.dragonheir.info/article/596
- Stable source ID: `WIKI-027`

- Boss为18秒循环；6–17秒对前排连续多段并控制；
- 历史解法让主坦用系统送的Light Spear和三件Tidal Force抗控制；
- Boss每技能回血，需要两个禁疗位轮转：Sigrid降攻+禁疗，Thia补持续禁疗；
- Ihuicatl提供护盾与二级防御提升；Estella做快速恢复；
- Boss威能前集中开Sigrid+Ihuicatl+Estella减伤/治疗；
- 若装备不达标，正文明确建议等第二天拿额外削弱宝石，不要浪费资源硬顶。

### Ooze Monster

- URL: https://www.dragonheir.info/article/597
- Stable source ID: `WIKI-028`

- 正常约四天收齐River Lord's Eyes；一眼越级以生存为先；
- Vicuc群体净化2个减益并给二级降攻；Ihuicatl在队友开威能时给盾，二人形成减伤循环；
- Garius+Estella提供低血线恢复；Tonalnan可作不依赖体系的单体主C；
- Boss三技能均叠毒，优先净化/免疫，再补防御提升或降攻、治疗/护盾；
- 同类不同等级Buff不会叠时长，等前一个结束再接下一个，避免浪费覆盖。
