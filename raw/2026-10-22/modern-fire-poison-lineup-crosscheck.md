# 现代火/毒阵容交叉核验：斯赖特是否必需、燃烧三件是否毕业

Captured: 2026-10-22

## 现代毒伤

### 2026-08 异界攻略

- URL: https://www.dragonheir.info/article/2829
- Stable source ID: `WIKI-008`
- 阵容：`蛇女 + 杜兰戈 + 图奇 + 蕾塔 + 欧勾克`
- 含义：当前跨服高配样例可以不带斯赖特；300心愿取得蛇女、图奇、欧勾克后确实已有可工作的骨架，斯赖特不是所有Boss的硬门票。

### 2026-07 大陆挑战高分攻略

- URL: https://www.dragonheir.info/article/2834
- Stable source ID: `WIKI-009`
- 阵容：`蛇女 + 斯赖特 + 图奇 + 卡拉维拉 + 纳萨尼尔`
- 明示替代：无斯赖特时可用柯林或杜兰戈替换；高配蕾塔、欧勾克等可转一辅四输出。
- 属性示例：卡拉维拉装备共享命中套并堆到450以上时，其他毒伤英雄只需130以上命中；图奇与斯赖特尽量堆技能急速。
- 含义：斯赖特是高价值伤害位，但属于可替换组件；Boss、共享命中和生存结构会改变第五人。

### 蛇女英雄页

- URL: https://www.dragonheir.info/heroes/24340
- Existing source: `WIKI-004`
- 推荐队友显示蕾塔、斯赖特、图奇等，支持斯赖特的高协同性，但英雄页推荐不等于唯一阵容。

## 现代燃烧

### 深海异界样例

- URL: https://www.dragonheir.info/article/2393
- Stable source ID: `WIKI-010`
- 阵容：`欧勾克 + 托维尔 + 派克西顿 + 杜瑞姆 + 卡尔弗`
- 明示替代：已有派克西顿时，杜瑞姆可替换成阿沙提乌斯；没有派克西顿时可改用比格斯。
- 含义：火拳与杜瑞姆在部分现代阵容里竞争同一个输出槽，不是永远同时上场。

### 斯卡尔英雄页

- URL: https://www.dragonheir.info/heroes/23060
- Stable source ID: `WIKI-011`
- 机制：全队伤害提高/减伤、分享自身增益、队友造成伤害后恢复生命；推荐队友含派克西顿、火拳、卡尔弗。
- 含义：现代燃烧常需要独立生存/增伤支点，三输出并非完整五人。

### S4 派克西顿培养建议

- URL: https://www.dragonheir.info/article/407
- Stable source ID: `WIKI-012`
- 文章把派克西顿定位为提升燃烧队PVE输出，并称其在PVE可作为杜瑞姆上位替代。
- 版本较旧，不能直接宣称当前全面上位；但足以否定“杜瑞姆永远不可替代”。

### 2026-05 大陆挑战高分样例

- URL: https://www.dragonheir.info/article/2706
- Stable source ID: `WIKI-013`
- 阵容：`玛舒图尔 + 杜瑞姆 + 派克西顿 + 卡尔弗 + 狄尔基`，火拳未上场。
- 文章要求派克西顿命中大于400并通过套装分享，杜瑞姆/卡尔弗命中可降至170以上；证明共享属性会改变整队配装。

## 修正后的规划语言

- `蛇女 + 图奇 + 欧勾克`：300心愿可启动骨架；斯赖特是高价值补件，不是绝对硬门票。
- `火拳 + 卡尔弗 + 杜瑞姆`：S2机制骨架；不能称“完整现代燃烧码”或“300毕业”。
- 现代燃烧还要根据内容从派克西顿、斯卡尔/欧勾克、托维尔、玛舒图尔等补件中选择，且火拳与杜瑞姆可能竞争席位。
- 所有跨服阵容都只用于机制与构筑结构；370国服技能数值、候选类别和装备环境仍待客户端复核。
