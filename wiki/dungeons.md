# 副本职能矩阵

没有玩家卡盒前，先用“必要职能”而不是死记五人名单。

| 场景 | 核心机制 | 最低职能组合 | 常见低配/通用卡方向 | 腐蚀队适配 |
|---|---|---|---|---|
| 地精据点 | 多波群怪、限时 | 聚怪/范围减益 + 2–3 群攻 | 西格莉德配群体减益；冰系群攻 | 中，成型前不如直接 AOE |
| 时空涡流/海王 | 最高生命单位吃定点雷击；后期伤害递增 | 最高生命主坦 + 群奶/减伤 + 降攻/减充能 + 2 输出 | 加里乌斯、海桑德拉、戴因等按卡盒替换 | 强于长战，但先保证生存 |
| 剧毒墓穴 | 坦克压力、Boss 护盾/召唤物与阶段机制 | 硬坦 + 双生存或驱散 + 单体/范围输出 | 先刷此本获取输出装通常最顺 | 中，需保护近战毒龙 |
| 诅咒墓穴/血王子 | Boss 增益、爆发窗口 | 驱散敌方增益 + 治疗/护盾 + 单体输出 | 格洛弗等驱散位 | 中，机制位优先于纯输出 |

## 370 开荒可直接用的历史低配模板

以下来自 2025 首发 S1 攻略，是机制模板，不保证 2026 层数和数值完全相同。

> 370目前是S1第1天：本节今天只使用“地精与低层首通”部分。14/16层队伍用于提前保留工具人，不建议今天为它们单独拉等级、技能或专属。

### 地精据点

`沃雷什/范围减益 + 西格莉德 + 2个群攻 + 聚怪/前排`

第一目标是三星首通，之后再保存自动轴。子夜与龙妈都不是这里的优先投资，缺群攻时用冰老头、拉瓦、维迪米尔等免费/蓝紫卡。

当前新手指南入口仍收录的地精1–12正文补出了1–6层手操：六波怪按“两名英雄清一波、剩余三名清下一波”交替；沃雷什必须先给群体减益，西格莉德再开范围追击；拉瓦先手后再让维迪米尔、罗薇娜开。历史五人为 `拉瓦 + 维迪米尔 + 罗薇娜 + 沃雷什 + 西格莉德`，370无需死抄人名，只需复现“前置减益→收割、两组轮转、不在一波交五大”的结构。

### 时空涡流/海王

Day 1低配骨架为：

`贝里克/加雷斯主坦 + 海桑德拉/加里乌斯治疗 + 戴因/埃斯特拉保护 + 两个最佳单体输出`

- 装备后主坦必须保持全队最高生命，承接历史“雷电之召”的最高生命锁定；
- 初次按1坦+2辅助+2输出，坦仍死就把一个输出换第二治疗/减伤；
- 贝里克/加雷斯承担二级降攻，戴因提供减伤与队友保护；
- 难度4后会轮换词缀，不能长期保存同一阵容不看环境；
- 当前新手入口建议早期可四同阵营+跨元素奶冲伤害，但火/毒白板不为亲和牺牲降攻与续航。

旧龙妈高分阵容与现代蛇女毒伤用于发现长战上限，不是首日最低阵容。下线前用最新练度重打一次，先拿稳定奖励档，再研究排行榜。

### 剧毒墓穴

官方蓝紫卡教程补充了机制级解释：四个磷火会在Boss单体攻击时概率协战；磷火带减益时协战概率下降。击杀磷火会对Boss造成真实伤害，而Boss二技能最多复活两个。因此“群体降攻/减益+范围清怪”同时承担生存和输出，不是可有可无的伤害前置。

历史低配骨架：

`加里乌斯 + 埃斯特拉/托因 + 2个输出 + 移除护盾/降攻位`

高层的关键不是五亲和，而是坦克扛过前两轮、及时处理 Boss 护盾与小球。攻略案例使用高命中“舒克”移除护盾并施加 2 级降攻；功能相同的英雄可替换。

更早的测试期对策卡长文还列出丹、伊莉娜、西格丽德、舒克、费尔巴斯作为减攻/机制方向。它们只用于识别可保留的蓝紫职能；公测后14层实队对舒克的破盾/降攻价值形成了后续交叉支持。

按死亡时间诊断比盲换阵容更有效：第一轮前倒坦，补坦克硬度（托因属性传递、冰盾/电盾、伊索尔德降攻盾）；第一至第三轮倒，补治疗量；第三轮后才倒，通常是小球存活过久导致输出不足，改用范围冰系输出。天然硬坦可试蓝橡树套，依赖威能保命的坦可试雪原守护者；奶妈穿先祖守护分摊伤害也是历史解法。

历史79级14层实队：`埃斯特拉 + 加里乌斯 + 伊西塔瑞安 + 复制姐 + 舒克`。埃斯特拉堆精通、加里乌斯堆防御、舒克约250命中；Boss出盾时手开舒克，前排残血时手开加里乌斯，其余自动，防御光环。这里的250是该作者当时配置，不是370低层硬门槛。

### 诅咒墓穴

官方正文说明Boss造成生命伤害后会吸血并削减目标生命上限；群体护盾能让伤害先打在盾上，从源头阻断这两项效果。Boss还会自加输出增益，所以敌增益移除/无效/窃取与大招前降攻、减伤、防御增加是独立硬职能，不能只靠多带治疗替代。

Boss 历史循环为 18 秒：约 6 秒给自己增益、12 秒强力单体并套盾、18 秒大招。最低职能是：

`硬坦 + 敌方增益移除 + 2级降攻 + 护盾/双增益覆盖 + 单体输出`

沃雷什/驱散位需要足够命中；保护技能应压在 Boss 18 秒大招前。先手动打通，再把时间轴保存为自动。

高层还会让Boss一次获得两个增伤，并在三技能移除我方增益后，对身上无增益者额外增伤50%。因此驱散位必须能稳定移除两个以上增益，己方则要在三技能前保证每人至少有可被移除后仍剩余的保护增益；单驱散和单增益覆盖都可能失效。

历史79级14层实队：`加里乌斯 + 伊西塔瑞安 + 复制姐 + 舒克 + 沃雷什`。舒克和沃雷什约250命中；第一次加里乌斯在Boss出盾后手开，舒克见盾开，沃雷什在Boss大招后稍等再开。高层蓝紫卡替代则有 `加里乌斯 + 舒克 + 格洛弗 + 纳萨尼尔 + 阿塔尔`，但拉条不稳定，需要手操。

### 腐烂墓穴

官方正文明确Boss会按自身减益数量强化一、二技能：减益越多，毒层越高、二技能目标越多。应分散站位并减少不必要减益；毒伤和寒霜被直接点名为不优先输出流派。三技能不受减益数量强化，所以禁疗/减疗/降攻仍可在收益足够时保留。对火系而言，狂野直接伤害比毒伤更自然；燃烧状态是否计入370当前减益计数仍需现场验证。

三条经过版本公告保留的解法：

1. 召唤物代替英雄被吞；
2. 全体隐身躲避锁定；
3. 无畏等爆发队在吞噬阶段迅速打出释放伤害。

同时准备减益移除/免疫，应对充能降低和 2 级攻击降低。子夜毒伤偏持续，龙妈偏单体爆发；若没有隐身/召唤逃课组件，两者都必须让出生存位。

测试期对策卡表把西格莉德、泰雅、艾琦丝列为禁疗方向，舒克列为破盾，泰雅、凯瑟琳列为减益应对；是否仍匹配370当前技能文本需在图鉴复核，但这些卡不应仅因蓝紫稀有度被忽略。

可复原的历史隐身样例为 `冰龙 + 冰盾 + 泰雅 + 光奶 + 冰女`：泰雅在吞噬锁定前开10秒全体隐身，光奶在一技能前给减益免疫，冰女负责破防/寒霜。低配以冰老头替冰龙、冰主角补盾。另一路是三召唤让召唤物承吞噬；两条都要按370当前锁定顺序重新对轴。

历史79级14层召唤实队：`埃斯特拉 + 加里乌斯 + 伊西塔瑞安 + 复制姐 + 叹息王`。Boss吞噬顺序为中→左一格→右一格；作者把小亡灵放中间、两条龙放左右，并调整复制姐与伊西塔瑞安大招顺序，避免复制小亡灵。高层隐身轴更具体：泰雅在每轮Boss二技能前开，二技能后约6秒吞噬，10秒隐身/免疫可覆盖二、三技能；凯瑟琳在第二轮一技能前行动，冰盾/电盾在二技能前套盾。辅助需追上历史18秒循环，且隐身仅保护远程输出。

### 天赋领域

首发平衡公告说明高层会针对本领域元素：炽焰领域压制火/毒，风暴领域压制电/光，冰霜领域压制冰/暗。因此火/毒账号也必须养一组跨元素蓝紫工具人，不能只练五名火毒。

当前新手指南正文进一步给出1–6层手操基线：

- 火毒素材本：Catherine在Boss威能前开免疫，第二阶段留技能、第三阶段前开；Garius可自净化，Ladehlia+Isitarian用召唤物清场。
- 电光素材本：Estella+Heksandra双治疗推进Boss阶段，幼龙带减益后再让Sigrid手动清场；Boss第二小阶段前先关自动。
- 冰暗素材本：Exhaustion或降攻存在时不交威能，等Boss第二技能后再开；Acilia/Catherine免控，Shook可驱散护盾。

这些是手操起点，不是370固定五人。完整Day1–7流程见 [战斗手册](../outputs/day1-7-combat-playbook.md)。

### 主线首周卡点

- The Blasphemous：18秒循环，6–17秒前排多段+控制；双禁疗错开，Boss威能前用降攻+二级防御提升/护盾+治疗。历史模板 `Garius + Sigrid + Thia + Ihuicatl + Estella`。
- Ooze Monster：三技能都叠毒；先净化/免疫，再接降攻/防御提升与治疗。历史一眼越级模板 `Vicuc + Ihuicatl + Garius + Estella + Tonalnan`，时间宽松，生存优先。

两个模板都来自当前新手指南总入口所收录的2025子页；370技能译名、赠送状态和秒点需实测。

## 装备副本推进顺序（通用基线）

多数 S1 玩家先推进剧毒墓穴拿输出装，再用输出装推进诅咒墓穴的防御装，随后处理腐烂墓穴的辅助套。实际顺序应服从账号卡盒：若某一机制本有天然克制英雄，可先跨级刷该本。

## 火 / 毒队的副本分工

| 内容 | 优先队 | 原因 |
|---|---|---|
| 主线群怪、地精 | 西格莉德通用队 | 毒伤启动和狂野单体都不如直接范围触发 |
| 海王、单体时空 | 狂野或成型毒伤 | 长战能完整发挥；先以生存档位为目标 |
| 大陆挑战·瓦妮雅菈历史词条 | 狂野 | 单体技能增伤适配狂野 |
| 大陆挑战·塔玛尔历史词条 | 毒伤 | 每层减益提高 Boss 受伤，毒层适配 |
| 腐烂墓穴 | 机制逃课队 | 隐身/召唤/爆发优先，流派不是第一决定项 |
| 炽焰领域高层 | 非火毒替补队 | 历史机制直接压制火/毒 |
