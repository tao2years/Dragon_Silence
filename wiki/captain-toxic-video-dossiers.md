# “机长该起飞了”蛇女 / 毒伤配队档案

更新：2026-10-23

## 执行摘要

本轮从作者 `机长该起飞了`（B站 UID `687980158`）的 127 条《龙息：神寂》投稿中，筛出 7 条有蛇女 / 毒伤构筑内容的视频、1 条只提供手操成绩的补充视频，并排除了 2 条由 Boss 名“双蛇 / 阴蛇”造成的误命中。可用主线不是一套固定五人，而是三层替换框架：

1. **输出发动机**：瑟潘忒弥斯负责爆毒；图奇 / 杜兰戈 / 斯赖特提供高频挂毒、共享或专武增益。
2. **破防 / 易伤与生存壳**：塞崔迪娅常驻于多数样本；蕾塔、混沌之子、欧勾克或“守门人”按 Boss 生存压力替换。
3. **技能轴随场景重做**：S8 暗蛇、双蛇四阶段、尾王一阶段的首轮秒点都不同；不能把某条视频的轴直接复制到另一 Boss。

这些证据全部是 **S7–S9 跨服社区样本**，不是 370 实测。伤害、命中阈值、神器译名和天赋节点只可作为起测值；370 仍需用客户端技能文本、Boss 秒点与战斗记录校准。

结构化事实表见 [`corpus/captain-toxic-builds.csv`](../corpus/captain-toxic-builds.csv)，不可变研究摘录见 [`raw/2026-10-23/captain-toxic-videos.md`](../raw/2026-10-23/captain-toxic-videos.md)。

## 1. 蛇女抽取与通用组队逻辑（BILI-026）

作者的核心判断是：蛇女被动会在队友施加毒素时追加爆毒，因此 **挂毒频率越高，蛇女被动触发越密**。这与项目现有蛇女技能结构相符，但作者对强度与抽取价值的评价仍属于社区意见。

- 高投入：作者举例“双斯赖特 + 蛇女”，追求高频毒伤与专武增益。
- 低投入：优先只拿蛇女；普通位可用 0 激励杜兰戈、图奇，或作者口中的“母狼（维卡）”。
- 杜兰戈常配迷蒙海螺并允许自由 / 默认轴，作为命中光环、高频挂毒和功能位。
- 作者列出的适用场景包括开荒、棋盘 / PVP、海王、爬塔和副本；这是覆盖面经验，不代表每个 Boss 都是最优解。
- 视频中关于当时自选池日期的预测已经过时，不进入当前卡池判断。

## 2. S7 亵渎女王：全自动平民毒素（BILI-027）

毒素部分使用蛇女、杜兰戈、图奇、欧勾克和“母狼（维卡，标准名待核）”。作者强调这队直接自动跑；同视频 01:28–01:40 展示的红色技能轴属于燃烧队，不能错配给毒队。

- 蛇女：4 红；头部优先破防，作者当时没有理想头。
- 杜兰戈：必须穿作者口中的“荒古 / 荒谷回响”生存套，主防御、副生命，并保留足够效果命中。
- 图奇：承担共享位，另一件装备名称在语音中不清晰。
- 母狼：作者口述“血肉缠身 + 共享”，神器为龙神珠。
- 欧勾克：堆攻击与精通。
- 成绩：作者口述约 22 亿，未恢复精确结算页，因此只能记为口述社区样本。

## 3. S8 暗蛇二阶段：杜兰戈低配（BILI-028）

阵容为 `蛇女 + 杜兰戈 + 蕾塔 + 城主 + 图奇`。这个样本最有价值的是站位和完整轴：作者要求覆盖三个蛋，杜兰戈放错格会漏目标。

### 配装

- 蛇女：4 红；没有好 4 红时改炉烟 3 件。主精通、副攻击。作者用元素亲和、杜兰戈光环与共享补命中，因此面板命中较低不能脱离队伍照抄。
- 蕾塔：迷蒙海螺；命中约 70。没有“天使”时以生存套保证活满，再考虑团队增伤。
- 杜兰戈：荒古 / 荒谷回响共享；作者给出的命中起测约 180，其余优先生存。
- 图奇：共享 + 毒牙；作者解释其高频追击可继续触发蛇女爆毒。
- 城主：暗夜英勇；优先保证易伤 / 破防链与一个共享位，神器可在龙神珠、金鹿角、管风琴等现有库存中权衡。

## 4. S8 双蛇三阶段：无天使 / 低激励生存版（BILI-029）

这条视频的目的不是展示极限输出，而是证明没有天使、蕾塔激励低时也能活满。作者把一位输出 / 增伤位替换为“守门人”生存位，城主带迷蒙海螺和暗夜英勇，蛇女甚至先用生存手套。

- 价值：给资源不足账号一条“先活满再提伤”的降配路径。
- 限制：作者只说技能轴沿用上一套，没有在本视频重放；五人标准名在队伍面板上仍有一位无法可靠映射。
- 因此本页不把它伪装成完整可复制码；先保留构筑思想，待队伍码或客户端角色页补齐。

## 5. S8 云顶双蛇四阶段：高配与低配（BILI-030）

### 高配：斯赖特版

`斯赖特 + 蛇女 + 图奇 + 城主 + 蕾塔`，两战合计 `23,627,834,923`。

- 蕾塔：胸、手均生命百分比；技能急速 75 是作者下限，80 可用，90 为目标。
- 蛇女：4 红、命中约 100；没有好 4 红则炉烟 3 件。
- 斯赖特：作者认为优先专武；无专武时宁可换杜兰戈。主堆攻击，命中接近蛇女。
- 图奇：共享 + 毒牙；命中约 250。
- 城主：前中位吃三个蛋，堆防御 / 生命，命中约 200。

轴：`斯赖特15.3 / 蛇女11.0 / 图奇15.1 / 城主12.5 / 蕾塔15.0 → 全员18.0`。

### 低配：杜兰戈版

`蛇女 + 杜兰戈 + 蕾塔 + 城主 + 图奇`，两战合计 `12,773,727,715`。

- 蕾塔：守门人法杖、生命主词条，急速 80 起测、90 目标。
- 蛇女：4 红或炉烟 3 件；作者因杜兰戈光环把命中起测降到约 90。
- 杜兰戈：偏暴击并保证前排约 2000 防御；神器在龙神珠、宝箱、天使类库存中择一。
- 图奇：共享 + 毒牙，命中约 211–233。
- 城主：奥术 + 共享 + 迷蒙海螺，命中约 200。

轴：`蛇女11.0 / 杜兰戈15.3 / 蕾塔15.0 / 城主12.5 / 图奇15.1 → 全员18.0`。

### 天赋

作者在约 04:48–05:14 逐页展示了斯赖特、城主、图奇与蕾塔的天赋路径，但视频小字与语音转写无法稳定恢复全部国服标准名。本轮只确认“天赋页已展示”，不根据图标猜节点；如果要在 370 落地，最小补件是对应英雄当前国服天赋页截图。

## 6. S8 尾王一阶段：17.37 / 17.55 两套循环（BILI-031）

### 高配：斯赖特 + 蕾塔

阵容 `蛇女 + 图奇 + 斯赖特 + 城主 + 蕾塔`，结算 `1,831,933,838`，作者称通常约 18.3–19 亿。

- 蛇女：4 红；命中约 95 时作者使用天赋“损人利己”。
- 蕾塔：守门人 + 月辉恩典，技能循环压到 15 秒。
- 斯赖特：主攻击，命中 120–140。
- 图奇：共享 + 二次判定腰带，并补少量急速。
- 城主：迷蒙海螺；命中够后补攻击，兼顾共享收益。

轴：`蛇女默认→17.37；图奇11.4→17.37；斯赖特11.6→17.37；城主11.2→17.37；蕾塔11.1→15.0`。

### 低配：杜兰戈 + 欧勾克

阵容 `蛇女 + 杜兰戈 + 城主 + 欧勾克 + 图奇`，结算 `1,342,244,425`；作者估 0 激励蛇女约 12.5 亿。

- 蛇女：装备沿用高配，但天赋改为“同归于尽”。
- 杜兰戈：血肉 + 奥术 + 共享；先补暴击，再堆急速。
- 图奇：命中约 150 后堆攻击。
- 欧勾克：面板急速 140，叠加场内 +30 后跑 15 秒自由循环。
- 城主：命中约 150–160 后补攻击，为共享提供面板。

轴：`蛇女默认→17.55；杜兰戈11.7→17.55；城主11.5→17.55；欧勾克11.6→默认；图奇21.2→15.0`。

该视频已在 Pass 68 复核，补入本作者专题便于横向比较。

- 子夜版：`子夜 + 蛇女 + 斯赖特 + 混沌之子 + 城主`，约 3.35B，队伍码 `S9261020QU5B7BX2`。作者强调子夜更依赖专武，蛇女改承担共享 / 精通辅助。
- 结论边界：只能说这一次王冠上路样本中图奇版更高，不能推出“图奇永远强于子夜”。

## 8. 跨视频可迁移结论

### 可以迁移

- 蛇女不是孤立主 C：高频挂毒、共享、破防 / 易伤和生存必须一起看。
- 杜兰戈是低配替代核心：同时补命中光环、多段挂毒与部分生存，但换下斯赖特会失去专武 / 高面板增益。
- 城主在多数样本中不只是“破防工具人”：还承担毒素易伤、共享面板、部分输出或前排承伤。
- 蕾塔的 15 秒循环经常是生存闭环，不是单纯伤害提速；移除她时必须补回降攻 / 生存职能。
- 命中阈值依赖队伍光环、亲和与共享，不能只抄单人面板数字。

### 不能迁移

- 不能把 S8 双蛇的 18 秒轴复制到 S8 尾王或 S9 王冠。
- 不能把跨服神器口语名直接当作 370 国服标准名。
- 不能用视频伤害比较不同赛季 / Boss 的角色强弱。
- 不能根据“低配”标签忽略激励、专武、场地词缀和宠物差异。

## 370 区起测建议

在拿到 370 当前 Boss 技能与账号卡盒前，只建议按职能做起测，不承诺复刻视频成绩：

1. 基础五人先试 `蛇女 + 图奇 + 杜兰戈 + 城主 + 生存位`。
2. 生存足够后，用斯赖特替杜兰戈，明确记录失去的命中光环 / 生存与换来的专武 / 输出。
3. 若用蕾塔替代生存位，先验证 15 秒降攻覆盖和末轮存活，不先看总伤害。
4. 每次只改一项：站位、一个首轮秒点或一件神器；连续跑三次并写入 `state/test-log.csv`。
5. 最小补件：370 当前 Boss 技能页、五人角色 / 激励 / 专武页、迷蒙海螺与关键神器文本、一次完整结算和死亡时间。
