# 灵光完整体、下位替代与双蛇双路线

更新：2026-10-23

## 先说结论

当前 S9 长战灵光的完整骨架是：

`塔蕾西亚（光龙） + 戴安莎（蝴蝶） + 弥菈希亚（天使） + 霍尔法斯特（书记官） + 索尔莫（牛牛/牛头）`

其中前四位构成灵光输出与能量闭环，第五位按 Boss 换机制位。S8 双蛇四阶段视频则是上一代：

`塔蕾西亚 + 弥菈希亚 + 戴安莎 + 林科斯 + 索尔莫`

S9 的直接版本更新是霍尔法斯特替林科斯。投稿测试称零激励霍尔法斯特已比五激励林科斯约高 15%，但这是测试服社区对比，不是 370 实测。

## 五个位置分别在做什么

| 位置 | 完整体 | 核心职能 | 移除后的损失 |
|---|---|---|---|
| 主 C | 塔蕾西亚 | 由攻击和最大生命共同出伤；收集/消耗灵光能量叠凝光，触发晶矢；威能强化期无视大量防御 | 没有同级一拖四主 C，整队上限与生存输出兼顾同时下降 |
| 能量发动机 | 戴安莎 | 给灵光队回能、延长法阵、通过光龙生命加成伤害继续回能 | 能量循环与光龙被动触发密度下降 |
| 生存/免疫 | 弥菈希亚 | 治疗、持续恢复、致死保护、复活、减益免疫；高激励提高持续与复活质量 | 不是“少一个奶”，而是同时失去保命、复活和免疫窗口 |
| 副 C/放大 | 霍尔法斯特 | 满能后向最高攻击灵光友军输能；灵光友军放威能后给 30% 增伤；高激励补光易伤 | 换回林科斯后仍有能量循环，但失去新版增伤与易伤上限 |
| Boss 对策位 | 索尔莫 | 高生命目标护盾、减伤与承伤；双蛇视频里负责让光龙长期不破盾 | 换列娜能得到推拉条，但双蛇四阶段会明显丢生存 |

## 投资档位

### 能运行的版本

- 塔蕾西亚本体；戴安莎本体；弥菈希亚本体；霍尔法斯特本体；索尔莫或符合 Boss 的生存机制位。
- 这是“机制闭环”，不是高榜配置。没有塔蕾西亚时，不建议把别的灵光输出硬称为同一套完整体。

### 高分版本

- 塔蕾西亚五激励是社区样本的上限档；I2 增额外晶矢，I5 缩短触发高阶箭的凝光层数，均直接提高输出。
- 弥菈希亚二激励会延长其施加增益；三激励提高复活血量，五激励增加被动保命次数。社区常把二激励视为重要档，但 370 仍以当前池规与客户端文本为准。
- 霍尔法斯特二激励扩大随机增益与光伤覆盖，五激励最高叠 20% 光易伤。预算有限先看 0→2，不默认追 5。
- 戴安莎与索尔莫的精确激励优先级未在这组视频中做单变量对照，不补造排序。

## 下位替代：按职能而不是按标签

| 缺谁 | 可用替代 | 得到什么 | 失去什么 / 何时不成立 |
|---|---|---|---|
| 霍尔法斯特 | 林科斯 | 开场与威能给最高攻击灵光队友能量，仍能维持旧版循环 | 少新版 30% 增伤、随机攻击/暴击增益与高激励光易伤；这是最直接的版本下位 |
| 索尔莫 | 列娜 | 推拉条、提速，适合生存压力较低或短战 | 双蛇四阶段作者实测不推荐，因 Boss 无视不死且列娜保人不足；不能把“提速”当“同等护盾” |
| 索尔莫 | 通用坦/盾/降攻位 | 只补当前 Boss 要求的承伤、盾或降攻 | 失去按光龙最大生命放大的厚盾与灵光/元素协同；需要重做亲和与技能轴 |
| 弥菈希亚 | 吉莉安、凯瑟琳或其他治疗/免疫位 | 能补治疗、持续恢复或免疫中的一部分 | 没有单卡同时补回致死保护、复活、免疫和增益延长；只能称开荒替代，不能称完整体 |
| 戴安莎 | 林科斯/莎赫拉等旧灵光组件 | 可补一部分灵光能量或旧体系联动 | 不能完整替代戴安莎法阵、全队回能和触发链；需按实战能量断点重调轴 |
| 塔蕾西亚 | 爱蒙拉达等旧灵光输出 | 能组成旧灵光队或填多队 | 不是一拖四光龙的等价替代；当前完整体的生命伤害、凝光与高防御穿透闭环不复存在 |

因此，真正可称“无痛下位”的只有 **霍尔法斯特→林科斯**。其余都是改体系或补单一职能。

## 双蛇四阶段：灵光配置

证据为 S8 社区视频 BILI-033，不是 370 / S1 当前事实。

| 角色 | 配装重点 | 首次 / 循环 |
|---|---|---:|
| 塔蕾西亚 | “铃铛”；满暴，重击约 240%，副生命；样本生命约 12.46 万 | `19.0 / 18.0` |
| 弥菈希亚 | 密修会 + 护盾增伤；补防御；天使联盟，无则太阳王军号 | `37.0 / 18.0` |
| 戴安莎 | 女巫的残留物；场地词缀下高命中，样本约 413；副攻击 | `19.0 / 18.0` |
| 林科斯 | 魔偶师套；尽量堆攻击，样本约 6020；金鹿角 | `18.5 / 18.0` |
| 索尔莫 | 闪金背心 + 圣河 10% 减伤 + 漩流破锋；主精通副生命，额外防御约 2000 | `默认 / 18.0` |

- 全自动，连续关卡独立计时关闭。
- 两战合计 `24,272,877,086`；作者口述五激励光龙约 71 亿且约 7:20 阵亡。
- 不推荐月辉恩典 / 暗夜类破盾后增益：该样本光龙六分半前不破盾，吃不到收益。
- 作者明确索尔莫天赋没点全仍可活满；视频没有给出可可靠抄录的完整天赋节点，所以这里只保留技能 `1/5/5` 和配装方向。

## 双蛇四阶段：毒伤配置

### 高配

`斯赖特 + 瑟潘忒弥斯 + 图奇 + 塞崔迪娅 + 蕾塔`

- 结算：`23,627,834,923`（两战合计）。
- 蕾塔：双生命主词条，技能急速 75 下限、80 可用、90 目标。
- 蛇女：4 红，命中约 100；无好 4 红用炉烟 3 件。
- 斯赖特：优先专武；没有专武作者建议直接换杜兰戈。主攻击，命中接近蛇女。
- 图奇：共享 + 毒牙，命中约 250。
- 城主：前中位吃三个蛋，全防御/生命，命中约 200。
- 轴：`斯赖特15.3 / 蛇女11.0 / 图奇15.1 / 城主12.5 / 蕾塔15.0 → 全员18.0`。

### 低配，也是当前 370 卡盒能直接起测的版本

`瑟潘忒弥斯 + 杜兰戈 + 蕾塔 + 塞崔迪娅 + 图奇`

- 结算：`12,773,727,715`（S8 社区两战样本，不能外推 370）。
- 蕾塔：守门人法杖、生命主词条；急速 80 起测、90 目标。
- 蛇女：4 红或炉烟 3 件；因杜兰戈命中光环，作者样本命中约 90。
- 杜兰戈：偏暴击，前排约 2000 防御；同时提供命中光环与高频挂毒。
- 图奇：共享 + 毒牙，命中约 211–233。
- 城主：奥术 + 共享 + 迷蒙海螺，命中约 200。
- 轴：`蛇女11.0 / 杜兰戈15.3 / 蕾塔15.0 / 城主12.5 / 图奇15.1 → 全员18.0`。

当前账号已确认拥有这五人而没有斯赖特，因此毒伤低配是可执行起点；上斯赖特不只是“多一个输出”，还会失去杜兰戈的命中光环与部分前排能力，必须重配全队命中和站位。

## 证据边界与 370 落地

1. 双蛇视频是 S8 跨服社区样本；370 当前仍在 S1，Boss 数值、场地词缀、神器文本与轴都可能不同。
2. 370 目前只有海王首日 `蛇女+图奇+城主+蕾塔+泥魔` 刚好活满的账号实测；没有双蛇当前技能页或上述灵光卡盒实测。
3. 因此现阶段可以照抄的是职能关系与首轮起测值，不是伤害数字。每次只改一个变量，连续跑三次，再写入 `state/test-log.csv`。
