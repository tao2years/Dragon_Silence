# 狂野火：龙妈旧骨架、现代缺口与使用场景

Updated: 2026-10-22

## 一句话判断

龙妈是历史上经过海王与 S1 终局验证的长线单体主 C，但 370 通过 S1–S5 溯影只能拿到旧骨架的一部分，无法取得 S6 狂野火龙。若没有可拉克/火巨魔等现代组件，选龙妈代表开启长期项目，不代表 300 抽后即成当前版本毕业队。

## S1 可启动骨架

历史常见五人：

`龙妈·芙罗拉 + 菲莉丝蒂 + 埃里奇 + 火系坦/盾 + 生存或机制位`

官方2025角色教学明确了旧狂野铁三角：菲莉丝蒂释放战技，帮助龙妈威能快速叠到三层；埃里奇提高狂野骰子结果，龙妈承担协同追加输出。它证明三人的机制闭环，但不代表该旧三角仍是S9毕业配置。

公开的两套历史样例：

- 2025 S1 社区强度帖：`芙罗拉 + 加莉卡 + 菲莉丝蒂 + 埃里奇 + 克莱索斯`，定位为海王强、开荒弱。
- 官方整理的复苏之龙高分样例：`卡斯帕 + 芙罗拉 + 埃里奇 + 阿道弗斯 + 菲莉丝蒂`；Boss 机制要求用增减威能清除龙狂层，菲莉丝蒂在该场景同时承担机制功能。

这两套阵容证明旧狂野能打长线单体，但不证明它们仍是 S9 最优五人。

## 六格如何给龙妈补件

若稀有输出选择龙妈，普通传说按以下顺序检查：

1. 菲莉丝蒂：旧狂野最优先组件，兼顾破防/威能机制与辅助输出；池内类别仍需 370 界面确认。
2. 埃里奇：旧 S1 单体补伤害，普通传说候选优先级较高。
3. 火系坦/盾：克莱索斯、加莉卡或当前界面允许的更强通用生存位。
4. 第四格才考虑第二体系组件；如果龙妈是主队，不能用两格火、两格毒平均拆分。

如果菲莉丝蒂不在四普通候选、可拉克也无法选择，龙妈方案立即降档。S6 狂野火龙确定不在活动时间窗内。

## 现代狂野缺口

S7 社区长帖把现代狂野上限绑定到：

- 狂野火地精：拔高体系上限，依赖专武；
- S6 狂野火龙：强副 C，明确不在 S1–S5 溯影；
- 龙妈：主攻手，但社区认为需要高激励与专武；
- 火巨魔：高价值辅助/生存组件。

因此“拿到龙妈”和“拥有现代狂野”之间至少还隔着辅助、现代副 C、神器与激励四类成本。

2026年3月另一篇专门面向预抽新手的社区长文也只把狂野核心列为龙妈、菲莉丝蒂、可拉克，并明确提示S6补强后仍高造价、平民不推荐。两份不同作者的社区材料在“单龙妈不是低成本队”上相互印证，但仍不替代370实测。

S8 大陆挑战赛的转载指南还给出一支现代机制队：`龙妈 + 菲莉丝蒂 + 可拉克 + 索尔戈斯 + 辛纳瑞尔`。该 Boss 会群控和降攻，队伍用辛纳瑞尔共享效果抵抗、高急速辅助维持环境。这说明龙妈体系的第五位首先服务 Boss 机制，不应把“必须五火/必须旧狂野三角加两输出”当固定公式。该材料尚未定位官方原帖，故仅作二手旁证。

## 内容分工

| 内容 | 龙妈适配 | 原因 |
|---|---|---|
| 主线/地精 | 低 | 狂野偏单体且依赖启动，范围触发队更省资源 |
| 海王长战 | 高 | 技能循环和多次狂野判定能完整发挥 |
| 历史瓦妮雅菈挑战 | 高 | 单体技能词条与狂野匹配 |
| 三墓穴 | 中 | 输出够，但驱散、降攻、免疫等机制位不可少 |
| 复苏之龙 | 中至高 | 需同时满足当期 Boss 的增减威能、生存与多队限制 |
| PVP | 当前社区评价低 | 长启动和高造价不适合把它当新区竞技主计划 |

## 装备与技能轴的证据边界

B站已经定位到“龙妈完美打造建议”“完美蜡烛”“火队号角”“S2狂野队海王搭配”等视频入口，另有无激励龙妈海王与技能轴案例；但页面正文/字幕接口持续返回 412。本研究库目前只把它们当视频线索，没有据标题臆造具体属性阈值。

在拿到可读配置前，装备只采用原则：

- 龙妈优先保证主输出属性和威能循环；
- 菲莉丝蒂/埃里奇按自己技能是否承担破防、判定或副 C 决定命中与输出；
- 主坦与治疗先达到海王生存时长，再从第二生存位换输出；
- 连续三次战斗记录狂野判定波动，单次高分不能视为稳定配置。

2026跨服正文现已补出两类Boss专用起测面板与手动点：一种用辛纳瑞尔在Boss第五技能前给龙妈威能，另一种让斯卡尔/索尔戈斯承担主要受击并堆抵抗与生存；详见 [火毒实战配装预设](../outputs/fire-poison-build-presets.md)。这些数字仍是跨服特定Boss参考，不覆盖上面的370证据边界。

## 370 决策闸门

选择龙妈前至少满足两项：

1. 四普通候选中确认有菲莉丝蒂；
2. 已有埃里奇、可拉克或其他可用狂野组件；
3. 接受 S6 火龙暂时无法获得；
4. 愿意把技能书、激励和专武预算集中给龙妈，而不是同时养子夜；
5. 已有另一套主线/地精群攻队。

只满足“喜欢龙妈”一项也可以选，但应明确标记为收藏/第二项目，而非新区最优资源方案。
