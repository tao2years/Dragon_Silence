# 毒伤体系：现代蛇女轴、旧子夜轴与长短战配置

Updated: 2026-10-23

## 结论先行

370 的默认目标应是现代蛇女轴，而不是旧子夜轴。跨服数据库的可核验技能文本显示，蛇女在场会降低全体敌人抗性，Toxin 每次命中又会触发范围爆毒并让施加者和蛇女永久成长启迪；它是整队发动机，不只是一个终结主 C。

因此 `100 欧勾克 → 200 图奇 → 300 蛇女` 的真实含义是：取得生存位、高频挂毒位和发动机，组成一支能工作的三件骨架；**不是 300 抽直接毕业。** 斯赖特仍是高价值后续补件，能用猛药和多段挂毒强化爆毒频率与上限，但不再把它写成现代毒伤的绝对硬门票。

无蛇女时，`子夜 + 斯赖特`仍是溯影中机制最闭环的旧双稀有选择，但它有一个硬前置：**普通候选或现有卡盒里至少要有杜兰戈、图奇之一。** 2025 国服 S1 的毒伤实战作者直接建议“没抽到杜兰戈或者图奇不要自选罗塞尔”。

2026年3月的预抽补充篇也把旧毒伤的稀有核心明确列成子夜+斯赖特，但作者同时在当时环境下不推荐毒伤，且没有列普通组件。它只能确认旧双核身份，不能反驳上述挂毒前置；更不能覆盖S7蛇女出现后的现代毒伤。若账号目标明确是未来蛇女，预抽应优先保留斯赖特、图奇/杜兰戈、欧勾克等可继续沿用的部件，而不是为了完成旧双核额外追子夜。

官方2025角色教学给出的最小协同链是：图奇被动提高挂毒效率，子夜按毒层追加伤害，柯林大招延续毒伤并完成对轴。这与玩家长战攻略的“图奇/杜兰戈负责高质量上毒、柯林负责维持、子夜结算”一致，但官方短视频摘要没有给出具体秒轴和装备阈值。

这条证据比纯强度榜更重要，因为子夜本身负责高毒层结算，必须有人稳定制造高质量毒层。斯赖特虽然能用“猛药”扩展有效层数，但不能替代所有挂毒与破防组件。

## 蛇女的精通增长与攻击/精通配比

蛇女不是无条件给五人同时增加精通。其被动在某名英雄成功施加的毒素命中时，给“该毒素施加者”和蛇女永久增加2点精通，各自最多增加200点；因此图奇、斯赖特、杜兰戈等实际触发者会成长，纯坦辅若没有触发毒素则不会凭空获得。蛇女在自己的毒沼期间可让直接毒素伤害继续施加毒素，所以塞崔迪娅等毒素直伤角色也可能在这个窗口成为触发者。激励5会改变基础增长量，国服精确文字仍以客户端为准。

跨服当前技能文本显示，蛇女有三种不同的属性结构：

- 威能技：`800%攻击`的派生伤害；
- 被动爆毒：`120%攻击`的派生伤害；
- 战技：`240%攻击 + 1200%精通`的普通毒素伤害。

通用精通规则是：派生伤害获得`精通/200`的增伤，且不能重击。因此对威能、被动爆毒以及受攻击上限约束的普通毒伤，可先用下式比较边际收益：

`派生伤害主体 ∝ 攻击 × (1 + 精通/200)`

- 增加`Δ攻击`的相对收益约为`Δ攻击 / 当前攻击`；
- 增加`Δ精通`的相对收益约为`Δ精通 / (200 + 当前战斗精通)`；
- 在只比较派生伤害时，`1精通 ≈ 当前攻击 / (200 + 当前战斗精通)`点攻击。

例：战斗中蛇女为5000攻击、基础300精通且已叠满被动200，实际精通约500。此时加100精通使派生部分约提升`100/700=14.3%`；加500攻击约提升`500/5000=10%`；1精通对派生部分约等于7.14攻击。若是6000攻击、500战斗精通，则1精通约等于8.57攻击。旧国服攻略给出的“1精通约9.4攻击”只是该作者当时面板的快捷换算，不是全账号通用常数。

战技还额外存在`1200%精通`的加算项：只看这一击，1精通贡献约等于5攻击（12伤害对2.4伤害，均为进入防御/增伤前的系数）。普攻和非派生直伤则更偏攻击。因此没有一个固定黄金比例；海王长战应把战斗中叠满后的精通计入，避免只看出战面板把精通堆得过饱和。实装上优先采用“攻击百分比主属性 + 高精通副词条”和“精通主属性 + 高攻击百分比副词条”的互补组合，再以实际海王三次平均伤害比较。

对370当前阶段，推荐先满足关键命中与存活，再让蛇女攻击、精通都增长；不要为追某个静态比例牺牲命中、技能轴或套装乘区。需要精确比较两件装备时，记录换装前后的最终攻击`A`、出战精通`E`以及海王中能否叠满200，再代入上述边际式。

### 派生伤害与蛇女完整出伤拆分

派生伤害不是一种元素，而是一类“由技能或状态额外触发的二次伤害”。它仍然可以是毒素、火焰等元素伤害；与普通直伤的主要差别是会被精通放大且不能重击。它也不等于真实伤害：蛇女的毒素派生伤害仍会经过目标防御、毒素易伤和其他适用增伤结算。

蛇女自身可见伤害可拆为：

1. 普攻与普通直伤：主要吃攻击，可重击；精通通常不直接放大。
2. 战技直伤：`240%攻击 + 1200%精通`毒素伤害，并施加3层毒素。
3. 威能首段：`800%攻击`毒素派生伤害，吃攻击与精通，不重击。
4. 被动爆毒：每次毒素成功触发蛇灵时，造成`120%攻击`范围毒素派生伤害；这是现代蛇女队高频核心。
5. 毒沼转换收益：10秒毒沼内，敌人每次受到“直接毒素伤害”时继续尝试施加毒素；这会把图奇、杜兰戈、斯赖特、塞崔迪娅等队友的直伤变成更多毒素触发机会。
6. 普通毒伤状态：由对应挂毒手施加，按周期造成毒素派生伤害；它与蛇女的“毒素标记→蛇灵爆毒”不是同一个伤害事件，但同样通常吃施加者攻击、精通与毒素易伤。

毒素标记本身更像发动条件，不应把每一层标记直接当成一跳独立伤害；真正可见的大量追加伤害主要来自蛇女被动爆毒、普通毒伤周期以及各角色技能直伤。精确到“一次三层毒素触发几次被动”的国服判定仍应以370录屏逐帧计数，不能只从英文文本猜测。

可用下面的简化式理解蛇女个人伤害结构，`A`为攻击、`E`为触发当下精通：

`D ≈ 威能次数×8A(1+E/200) + 爆毒次数×1.2A(1+E/200) + 战技次数×(2.4A+12E) + 普攻/其他直伤`

实战最终还要乘目标防御、30%毒素易伤、元素/派系增伤、装备增伤等；不同乘区不能简单相加。

### 长战叠满200后的常见配比带

长时间海王中，若蛇女能较早叠满额外200精通，应以`出战精通+200`作为大部分战斗的比较值。以5000攻击为例：

| 出战精通 | 长战精通 | 再加100精通对派生部分的收益 | 100精通约等于多少攻击 |
|---:|---:|---:|---:|
| 100 | 300 | 20.0% | 1000 |
| 200 | 400 | 16.7% | 833 |
| 300 | 500 | 14.3% | 714 |
| 400 | 600 | 12.5% | 625 |
| 500 | 700 | 11.1% | 556 |

上述等价攻击只针对攻击系数型派生伤害；蛇女战技固定为1精通约等于5攻击，普攻则完全偏攻击。因此更实用的起测区间是：

- 出战精通低于300：精通通常仍是高优先级，尤其短战尚未叠满时；
- 出战精通约350–450：长战变成550–650，是海王较均衡的起测带，随后优先比较高质量攻击百分比副词条；
- 出战精通约450–550：长战变成650–750，继续堆精通已经明显稀释，除非新装备同时带来更好套装、攻击或技能循环；
- 出战精通高于550：不视为绝对溢出，但通常应先检查攻击是否过低、是否牺牲了命中/套装/急速，以及实际伤害中战技占比是否足以支持继续堆精通。

跨赛季逐帧样本中的蛇女分别出现约`+3565攻击/+442精通`和`+4917攻击/+528精通`的装备增量，可作为“攻击与精通同时堆、不是单堆一项”的旁证，但这些是装备加成而非完整总面板，也不是370的毕业线。

## 塞崔迪娅与迷蒙海螺

塞崔迪娅威能技的两段毒素伤害和10秒30%毒素易伤，是蛇女队的独立乘区窗口。当前可复核的王冠轴为蛇女10.0秒、塞崔迪娅11.5秒、斯赖特11.7秒、图奇11.8秒：先由蛇女开毒沼，再由城主上易伤，挂毒手紧随其后，能让主要爆毒落在易伤窗口内。

迷蒙海螺存在版本文本差异：旧文本是“佩戴者威能技施加的减益被抵抗时，概率补上不可抵抗的2级防御降低”；当前跨服资料另收录了“对已有减益的目标再次施加减益时，补3秒2级防御降低”的改版文本。若370客户端写的是前者，那么塞崔迪娅命中足够、30%毒素易伤成功施加时，海螺本来就不会触发；它是失败保险而非常驻破防神器。故意压低城主命中换取海螺触发，通常会拿稳定的30%毒素易伤去赌破防，不推荐。

若客户端写的是改版文本，则需确保目标先有另一项减益、佩戴者随后成功施加新减益；3秒持续时间很短，必须逐帧看状态栏或战斗日志，肉眼很容易错过。2026跨服腐蚀攻略把海螺放在高命中蕾塔身上，并让塞崔迪娅改带龙神之珠，说明海螺更适合由高频、稳定减益的辅助承担，而不是固定占用城主神器位。

防御降低与30%毒素易伤不是同一乘区：防御降低提升普通/派生的非真实伤害，毒素易伤只提高对应毒素伤害；腐蚀结算中的真实伤害不吃防御降低。蛇女的威能和被动爆毒明确属于毒素派生伤害，因此会受有效破防影响，但不能因为城主已经有毒素易伤就把两者视为重复效果。

因此 300 抽后的过渡队可用：

`蛇女 + 图奇 + 欧勾克 + 独立前排 + 破防/净化/机制位`

拿到斯赖特后的伤害模板为：

`蛇女 + 斯赖特 + 图奇/杜兰戈 + 欧勾克/蕾塔 + 前排或Boss机制位`

若关卡必须独立坦克，不能机械照抄五毒；欧勾克与蕾塔也不应默认同时上，两者都占生存槽，按 Boss 是否需要不死、全体净化、持续降攻或减益延长来选。

## 2026跨服实队：斯赖特高价值但可替换

两份2026攻略给出了互补证据：

- 异界高配样例：`蛇女 + 杜兰戈 + 图奇 + 蕾塔 + 欧勾克`，没有斯赖特；
- 大陆挑战样例：`蛇女 + 斯赖特 + 图奇 + 卡拉维拉 + 纳萨尼尔`，正文明确无斯赖特时可换柯林或杜兰戈。

因此抽卡优先级应写成：先取得蛇女发动机、稳定挂毒和生存，再按Boss与已有卡盒补斯赖特。它通常能提高上限，但“没有斯赖特就不能玩蛇女”已被实队反证。

大陆挑战样例还有一个重要配装条件：卡拉维拉用共享命中套并堆到450以上时，其他毒伤英雄只需130以上命中；图奇、斯赖特则尽量堆技能急速。这说明命中阈值不能脱离共享属性位复制到370。

完整的“无共享 / 有共享 / 特殊状态上限”起测配置已拆到 [火毒实战配装预设](../outputs/fire-poison-build-presets.md)。尤其要注意：另一现代 Boss 同时最多保留四个状态，后施加会覆盖最早状态，盲目堆减益可能把关键破防挤掉。

S8 大陆挑战赛的二手指南进一步说明毒伤的场景优势更偏多目标：分身受击计分的乔伊斯、三首领同场的杜瑞姆都点名毒伤/燃烧适配；但前者需要频繁驱散，后者需要解除或免疫群体降攻。这是“毒伤能吃多目标收益”的现代旁证，不代表蛇女队可以忽略机制位。

## S1 海王长战轴

历史实战队：

`子夜 + 图奇/杜兰戈 + 柯林 + 泥中魔 + 欧勾克`

作者比较后倾向 `子夜 + 图奇 + 柯林` 为输出三核，称其能稳定维持 40 层；其个人测试中图奇伤害高于杜兰戈。该结论只代表 2025 S1 账号与装备环境，不直接证明 2026 S9 当前数值排序。

角色任务：

- 子夜：在高毒层窗口进行结算；历史配装主攻攻击与精通，而非双暴。
- 图奇/杜兰戈：制造高质量毒层，并携带破防神器。
- 柯林：刷新/扩散毒层、推条或维持覆盖；长战可刻意避免自己覆盖高属性毒层。
- 泥中魔：三只耳套装 + 太阳王军号，提供全队持续增伤的历史方案。
- 欧勾克：先祖守护/生存套，精通提高治疗。

### 长战柯林

历史作者给出两种方案：

1. 不堆急速、尽量 0 命中，天赋走延长毒伤方向；让图奇/杜兰戈的高属性毒层成为主要来源。
2. 带沙漏、堆急速但仍尽量低命中，以推条和刷新为主。

国服毒伤触发与国际服旧资料存在差异，因此不能照搬国际服“柯林必须堆命中”的说法。

## 短副本启动轴

短战目标不是毒层最终质量，而是尽早让子夜启动：

- 柯林：急速 + 沙漏 + 命中，快速铺毒/刷新；
- 图奇/杜兰戈：选择更快挂毒的天赋方向；
- 子夜：尽早进入高层结算窗口；
- 如果第一轮仍超时，先换一个生存位为输出；如果第一轮死亡，则反向补降攻/护盾。

这与海王长战的低命中柯林恰好相反，必须保存成两套装备和技能预设。

历史同作者的神器对比，在相同账号环境下：子夜专武队伍常见约 5.1 亿，鹰身人指甲约 4 亿、腐臭墨水约 3.9 亿；但测试含破防概率、专武概率和装备差异，只能说明专武上限与稳定性差别，不能按比例外推到 370。

## 370 抽卡闸门

在溯影确认页依次检查：

1. 稀有输出是否同时存在子夜、斯赖特；
2. 普通传说是否至少存在图奇或杜兰戈；
3. 是否能补欧勾克或另一可靠生存位；
4. 若只有子夜 + 斯赖特、却没有任何高质量挂毒位，暂不确认选择；
5. 若已有蛇女，则把子夜的机会成本与第二流派核心比较。

## 证据边界

- 子夜/柯林/图奇/杜兰戈的详细轴来自 2025 S1 社区实战，可作为机制基线。
- 斯赖特猛药与子夜的联动来自官方账号刊登的 S2 玩家攻略。
- 蛇女、斯赖特、图奇、欧勾克的具体技能结构来自国际服第三方数据库，属于跨版本文本证据；国服当前数值仍待客户端截图。
- 斯赖特可替换与无斯赖特高配样例来自2026跨服攻略 `WIKI-008`、`WIKI-009`；它们证明构筑存在性，不承诺370同伤害。
- 蛇女在当前新区的优先级来自 2026-09/10 的国服社区共识与心愿池实况，不等于官方强度承诺。
- 2026-03预抽补充篇 `CN-COMM-002` 仅能确认S7前旧毒伤的子夜+斯赖特双核口径；其“毒伤弱”属于单作者、旧环境评价，已按时间边界隔离。
- 370 仍需以当前技能文本、天赋、装备套装和海王 Boss 为准重新跑三次稳定性测试。

2026-10-21的B站王冠毒伤攻略由作者公开了“有子夜”和“无子夜”两条队伍码，至少证明S9当前环境存在不依赖子夜的毒伤配置。另两条S9视频分别讨论四阶段双蛇毒伤，以及三阶段毒伤的两套存活方案。

两战合计 `13,704,867,164`（`5,484,101,988 + 8,220,765,176`），结算页显示约6分48秒。已恢复的关键起测面板和18秒轴如下：
