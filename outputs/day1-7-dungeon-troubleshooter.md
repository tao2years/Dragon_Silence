# 370区 Day 1–7 地下城故障排查表

Updated: 2026-10-22

用途：失败后先按“死在哪里、Boss身上发生了什么”换一个职能，不要整队推倒重练。370当前为S1 Day 1，今天只推进已开放层数的首通；本表同时提前标记后续三墓穴的工具人。

## 一眼选择

| 地下城 | 首选结构 | 火/毒适配 | 第一优先检查 |
|---|---|---|---|
| 地精据点 | 范围减益→西格莉德收割 + 两组群攻轮换 | 单体龙妈/子夜不优先；燃烧/毒伤启动慢时先用直伤群攻 | 是否把五个大招交在同一波 |
| 剧毒墓穴 | 硬坦 + 群体降攻/减益 + 持续治疗 + 2群攻 | 毒伤群攻有机制优势；火系只要能快速清四个磷火也可 | 磷火是否带减益、是否清得掉 |
| 诅咒墓穴 | 群盾 + 敌增益移除/无效 + 降攻/减伤 + 单体输出 | 火/毒可做输出，但不能挤掉盾与驱散 | Boss吸血、生命上限下降是否仍发生 |
| 腐烂墓穴 | 免疫/净化 + 分散 + 最少关键减益 + 直接伤害 | 毒伤不优先；燃烧是否算减益待370验证；狂野直伤更自然 | Boss身上减益数是否让技能升级 |
| 天赋领域 | 跨元素坦辅 + 对应机制位 + 非受压制输出 | 炽焰高层会压火/毒，必须保留跨元素蓝紫卡 | 是否因硬凑亲和而缺免疫/驱散 |
| 海王 | 最高生命主坦 + 2生存/机制 + 2单体输出 | 毒伤、狂野适合长战；首日先活到结算 | 最高生命是否真在主坦身上 |

## 剧毒墓穴：四磷火协战

推荐槽位：`硬坦｜群体降攻/减益｜持续治疗｜群攻1｜群攻2`

官方机制显示：四个磷火会在Boss单体攻击时概率协战；给磷火施加减益可降低协战概率。击杀磷火还会对Boss造成真实伤害，但Boss二技能最多复活两个。

| 失败症状 | 判断 | 只换这一项 |
|---|---|---|
| 坦克第一轮就倒 | 四磷火协战未压住或坦度不足 | 先把范围减益/降攻覆盖四怪；再换更硬坦，不先加第三输出 |
| 坦能活但全队掉血 | 治疗覆盖断档 | 换持续群疗/减伤，技能压在Boss攻击前 |
| 活得住但超时 | 磷火清理慢，未吃到真实伤害 | 把一个单体C换范围C；让范围技能同时覆盖Boss和四怪 |
| 小怪刚清又复活 | 正常二技能机制 | 留下一组AOE处理复活怪，不要第一轮交完所有威能 |

火/毒执行：现代/旧毒伤的群体挂毒能同时压协战并清小怪，是明确适配场景；但Day 1卡盒不完整时，用任意范围减益+西格莉德比硬上半套毒伤更稳。

## 诅咒墓穴：盾与驱散是硬门票

推荐槽位：`硬坦｜群体护盾｜敌增益移除/无效｜降攻/减伤｜单体C`

| 失败症状 | 判断 | 只换这一项 |
|---|---|---|
| Boss越打血越多 | Boss生命伤害转化为治疗 | 盾覆盖Boss伤害窗；不是单纯补输出 |
| 坦克生命上限持续缩短 | 护盾未挡住生命伤害 | 提前开盾，确保伤害先打盾 |
| 某轮突然秒坦/秒后排 | Boss输出增益未移除，或爆发窗无降攻 | 补稳定驱散/增益无效；在大招前覆盖降攻/减伤/防御增加 |
| 护盾有了仍扛不住 | 只解决了吸血，没解决爆发 | 增加降攻/减伤，而不是再塞一个奶后被生命上限压死 |

火/毒执行：只保留一个最强单体输出位。龙妈、子夜、蛇女或燃烧主C都可竞争这个位置，但谁练度高用谁；盾、驱散、降攻三职能不齐时不讨论五火/五毒。

## 腐烂墓穴：主动少上减益

推荐槽位：`硬坦/吞噬对策｜减益免疫｜净化｜直接伤害1｜直接伤害2`

官方机制显示：Boss身上减益越多，一技能毒伤层数越高、二技能波及目标越多。三技能不受这个计数强化，所以禁疗/减疗/降攻可在确有收益时保留。

| 失败症状 | 判断 | 只换这一项 |
|---|---|---|
| 全队毒层迅速堆高 | 没有在施加前免疫或施加后净化 | 先补免疫/群净化并对齐时间 |
| 二技能一次打多人 | 站位过密或Boss减益过多 | 五人分散，减少非必要毒、寒霜、破防等状态 |
| Boss吞噬后回血过多 | 缺禁疗/减疗或释放阈值不足 | 只保留一个高价值禁疗/减疗，或用爆发/召唤/隐身解吞噬 |
| 蛇女/子夜队越打越痛但自己先死 | 毒伤状态反向强化Boss | 换直接伤害队；毒伤留给剧毒墓穴/海王 |

火/毒执行：旧毒与现代蛇女线默认不进本；火系优先考虑狂野等直接伤害。燃烧状态是否被该Boss计入减益必须现场看图标/技能计数，未确认前不要把燃烧当默认解。

## 记录格式

每次失败只记五项：`层数｜阵容｜死亡秒数｜Boss当时技能/状态数｜下一次只改什么`。连续三次稳定后再保存自动轴；若同时更换三名英雄、装备与时间轴，就无法知道真正解决了什么。
