# 370 区火 / 毒账号规划（心愿 / 溯影版）

Updated: 2026-10-22

## 先给结论

当前精选Ⅲ腐蚀池不下 300。对只有约 300 橙骰、偏好火/毒的账号，最值得等的是 370 是否在 Day 10–30 观察窗内开放与 2026-04 官方“心愿召唤”同规则的池。开放日样本彼此冲突，不能再写死 Day 10。

这里要特别区分：腐蚀与毒伤都使用毒素元素角色，但前者围绕腐蚀值/腐化真伤，后者围绕 Poison/Toxin、猛药与爆毒；当前腐蚀池不会自动补齐蛇女毒伤线。

官方长图已经复核：该池先自选 `2 名稀有输出传说 + 4 名普通传说`，六档为 `100 / 200 / 300 / 400 / 600 / 800`；普通传说在 100、200、400、600 领取，稀有输出在 300、800 领取。**300 抽只能拿前两名普通传说和第一名稀有输出，不是拿齐两主 C + 四组件。**

近期新区社区正好给出 `100 欧勾克 / 200 图奇 / 300 蛇女` 的停抽方案。三人不是官方固定奖励，而是玩家在各档的自选方案；若 370 候选相同，这正是你的低后悔路线。

推荐顺序：

1. **先检查预言召唤3.0。** 它只覆盖S1–S5、抽不到蛇女，但可锁 `斯赖特 + 欧勾克 + 图奇/杜兰戈` 等未来蛇女队组件；只有100抽结果足够好且不破坏心愿300现金流时才兑现。
2. **目标心愿池确认前不碰腐蚀深抽，保留 300。**
3. **心愿池若含欧勾克、图奇、蛇女：按已有卡盒去重，默认100 欧勾克 → 200 图奇 → 300 蛇女，拿到即停。** 若预言100抽已拿欧勾克/图奇，就把对应普通档换成缺少的斯赖特以外普通组件或通用辅助，不重复选。
4. **之后再攒的资源优先看斯赖特、杜兰戈或当前Boss机制位，不追800档第二稀有，除非预算确实达到800且第二体系组件已齐。** 斯赖特通常提高上限，但已不是现代蛇女队的硬门票。
5. **若370没有蛇女心愿：再根据溯影实际阈值决定旧毒伤或龙妈项目，绝不预设“300拿双主C”。**

当前S9王冠毒伤作者已经公开“有子夜”和“无子夜”两条队伍码，说明现代毒伤确实可以在不带子夜的配置下工作。它不证明370能低配复刻，但进一步降低了“为了毒队先拿子夜”的必要性。另有与本规划几乎同构的当期玩家提问：已经存300准备等毒蛇、又想抽精选中的城主；视频作者明确提醒精选不一定给城主。因此，不为普通传说概率位打破300预算。

## 方案 A：300 抽现代毒伤（首选）

前提：370 心愿召唤与官方长图同规则，且候选页允许选择以下三人。

| 里程碑 | 自选 | 作用 |
|---:|---|---|
| 100 | 欧勾克 | 毒系生存、净化/续航方向，跨队价值高 |
| 200 | 图奇 | 高质量挂毒、副 C，解决毒层启动 |
| 300 | 瑟潘忒弥斯（蛇女） | 现代毒伤主核 |

300 后的队伍骨架（可用，但未毕业）：

`蛇女 + 图奇/杜兰戈 + 欧勾克 + 坦克/降攻 + 破防或机制位`

后续补到斯赖特时可采用高伤害模板：

`蛇女 + 斯赖特 + 图奇/杜兰戈 + 欧勾克 + 坦/破防/机制位`

国际服数据库把这三张卡的职责拆得很清楚：蛇女负责 Toxin 爆毒、全体削抗与启迪成长；图奇靠多段攻击和启迪增箭高频铺 Poison；欧勾克负责 5 秒不死、延迟治疗、驱散和降攻。斯赖特再通过开场猛药、多段挂毒和猛药转毒提高伤害循环上限。因此 300 档是“发动机 + 挂毒 + 生存”的高性价比起点。2026实队同时证明无斯赖特时可用杜兰戈/柯林或额外机制位，后续第一补件要按Boss和卡盒决定，但仍不优先子夜。

这条路线只在候选与领取档位都亲眼确认后执行；自选一旦确认不能修改。

一篇成文于S7的长帖把蛇女加入后的毒伤评为T1、接近T0，并指出其主要短板不是伤害闭环，而是一拖四辅助的生存能力与后续数值膨胀。该作者此前对S8“冰爆/霹雳/燃烧”三路补强有一次成功回测，因此这条意见值得当作环境线索；但它仍是玩家评级，不替代370实际排行榜。对你的含义是：蛇女线优先解决输出闭环，副本成败往往取决于欧勾克/坦克/降攻位，而不是再塞第五个毒伤输出。

## 方案 B：没有蛇女时做旧毒伤

前置闸门：账号或前两档普通传说里至少能拿到杜兰戈、图奇之一。国服 S1 毒伤实战作者明确建议，没有这两名高质量挂毒位时不要选子夜。

长期目标是：

`子夜·罗塞尔 + 斯赖特 + 杜兰戈/图奇 + 欧勾克 + 生存/破防位`

但若活动沿用 `100/200/300/400/600/800`，300 抽只够一名稀有输出。此时第一稀有应根据卡盒二选一：

- 已有斯赖特：300 选子夜；
- 已有子夜或现代毒核：300 选斯赖特；
- 两者都没有：不要把这条线写成“300抽完成闭环”，先看是否有更好的单核路线。

只有370游戏内明确显示改版为300拿两名稀有输出，才执行 `子夜 + 斯赖特` 双核计划。

## 方案 C：第二项目优先观察燃烧火

火系不只有龙妈。若后续活动候选能在300档实际拿到 `阿沙提乌斯（火拳） + 卡尔弗（船长） + 杜瑞姆`，可以形成S2燃烧启动骨架：船长铺引燃，杜瑞姆施加焚毁增伤，火拳移除燃烧并触发爆燃。爆燃是小范围溅射，多目标密集关尤其合适。

这条线当前排在蛇女毒伤之后、龙妈之前；原因是三人的池内稀有分类与370可选名单尚未截图确认。新增复核显示，现代燃烧常加入派克西顿以及斯卡尔/欧勾克等生存增伤位，且火拳与杜瑞姆在部分Boss会互相替换；所以三件只能称启动骨架，不能称300毕业。不要为了“我喜欢火”就把300骰在毒、燃烧、狂野三边各投一点。

成本警告：S7社区长帖把当时燃烧排在T2，认为火拳上限不足，并把杜瑞姆视作队内实际核心C、强调其强依赖5激励，卡尔弗主要承担破防。这说明“300拿到三张名字”也不等于燃烧低成本毕业。燃烧仍可作为偏好驱动的第二项目，但必须把杜瑞姆激励、破防位和后续补强一起计价。

## 方案 D：龙妈火系项目

龙妈是长战狂野项目，不是新区万能开荒卡。只有已有菲莉丝蒂、埃里奇、可拉克/火巨魔等组件时才把她作为稀有输出目标；S6 狂野火龙不在 S1–S5 溯影范围。

旧骨架参考：

`龙妈 + 菲莉丝蒂 + 埃里奇 + 狂野触发/增益位 + 生存位`

300预算若先完成蛇女线，龙妈只列为第二阶段收集目标，不同时投入技能书、专属和激励。喜欢火/毒可以双项目长期养，但第一周只能精养先成型的一队。

## 预算分层

| 可支配橙骰 | 建议 |
|---:|---|
| <300 | 全部停手，不在独立限时池垫抽 |
| 300 | 若规则与候选吻合，执行欧勾克→图奇→蛇女 |
| 400–600 | 通常仍在普通传说档，不等于得到第二主C；按组件价值决定是否继续 |
| 800 | 才是官方心愿六格拿齐线；仅高预算且第二稀有明确有用时考虑 |

## 抽前六项检查

1. 六档是否确为 `100/200/300/400/600/800`，还是370专属改版；
2. 第3档和第6档是否分别领取两名稀有输出；
3. 蛇女、欧勾克、图奇是否都在各自候选范围；
4. 选择确认后不可修改的提示；
5. 活动结束日期、累计是否独立、未领邮件规则；
6. 当前骰子总量是否能一次到达目标档，不做半程垫抽；具体记账见 [370抽数预算](370-pull-budget.md)。

## 资源纪律

具体到命中、急速、抵抗、启迪与手动轴时，按 [火 / 毒实战配装预设](fire-poison-build-presets.md) 区分无共享命中、共享命中和特殊状态上限；不要把某一跨服Boss的阈值套到全部370副本。

- 技能书先给通用坦/奶/减益手，再给已确定成队的主 C。
- 地精、主线用西格莉德触发队，不要求毒伤或狂野承担群怪。
- 海王与单体挑战再上火/毒专队；毒伤先保证挂毒覆盖，狂野先保证判定次数与技能轴。
- 专属神器只为已经稳定上场的核心兑换，重复金优先评估通用红神器和机制神器。
