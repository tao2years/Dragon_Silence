# 370 区公开卡盒阵容模板

Updated: 2026-10-22

这些阵容可以在没有账号截图时先执行。名字阵容来自首发 S1 官方/社区案例，核心价值是职能结构；2026 年 370 区的具体层数、数值和技能轴仍需实测。

## 1. 主线、探索与早期通用队

官方首日思路可整理为：

`任意可靠前排 + 伊西塔瑞安 + 埃斯特拉 + 西格莉德 + 沃雷什`

- 沃雷什先施加范围减益，西格莉德再触发群体伤害。
- 伊西塔瑞安承担召唤/补伤害，埃斯特拉保生存；前排只比较谁能稳定活到第二轮威能技。
- 若缺其中一人，按“前排 / 生存 / 群体减益 / 西格莉德 / 群攻”替换，不必追五同元素。

这是新区第一周的主力，而不是强行让子夜或龙妈承担所有内容。

对370当前S1第1天，先把这五个职能升起来。即使预抽码出现蛇女队或燃烧队组件，也只替换输出/机制位，不要同时另养一整队。

## 2. 地精据点

低配骨架：

`范围减益手 → 西格莉德 → 群攻 1 → 群攻 2 → 聚怪/补刀`

操作重点：

1. 第一波不要把所有威能技浪费在残血怪上；保存至少一个范围技能给下一波。
2. 让减益覆盖先于西格莉德威能技；命中不足时先补命中，而不是继续堆攻击。
3. 龙妈和子夜都是单体/启动型投资，除非本身练度远高于其他人，否则地精不优先上。

## 3. 海王 / 时空涡流

### 通用保底线

`最高生命主坦 + 群体治疗/减伤 + 降攻/减充能 + 主C + 副C`

- 主坦生命必须保持全队最高，避免定点伤害跳到后排。
- 第一次只求活到结算；记录死亡秒数后，才决定把第二辅助换成输出。
- 同一阵容连续跑三次，伤害和死亡点稳定后才算可用。

### 毒伤旧链

`主坦 + 欧勾克/强治疗 + 斯赖特 + 子夜 + 杜兰戈/图奇`

- 斯赖特先建立猛药与毒层，子夜在高层数窗口引爆；杜兰戈偏单体效率，图奇偏群体/副 C。
- 如果 Boss 的攻击压力导致子夜频繁倒下，先牺牲一个毒位换降攻/护盾，而不是硬凑五毒。
- 有蛇女时，蛇女取代子夜进入现代主链的价值更高属于当前社区判断，需用账号实测确认。
- 海王长战的历史细化方案是让柯林低/零命中，避免覆盖图奇/杜兰戈制造的高属性毒层；短副本则相反，让柯林堆急速、命中和沙漏抢启动。两套预设不要混用。

### 现代蛇女过渡链

300档骨架：

`主坦 + 蛇女 + 图奇 + 欧勾克 + 破防/机制位`

- 蛇女负责削抗、Toxin爆毒与长战启迪成长；图奇负责多段高频铺毒；欧勾克提供不死、延迟治疗、驱散和降攻。
- 这套无需斯赖特也能开工。2026跨服异界已有 `蛇女 + 杜兰戈 + 图奇 + 蕾塔 + 欧勾克` 的无斯赖特高配样例；大陆挑战正文也明确斯赖特可由柯林或杜兰戈替换。拿到斯赖特后，按关卡生存压力替换破防位、第二生存位或低效挂毒位，不要默认四个毒输出全上。
- S8“0命蛇女无大老鼠”已逐帧恢复为`图奇 + 0激励蛇女 + 城主 + 金面具生存辅助 + 蕾塔`，两战合计16.49B；第四人的官方姓名仍待队伍码/客户端确认。这是完整无斯赖特构筑证据，但仍不能把跨赛季伤害承诺给370。
- S9王冠两码也已逐帧还原：无子夜码是`蛇女 + 斯赖特 + 混沌之子 + 城主 + 图奇`，录得3.85B；有子夜码把图奇换为子夜，录得3.35B。该单次同账号对照支持“子夜非必需”，不等于图奇在所有Boss都固定更强。
- S9三阶段生存视频的评论表明：混沌之子若天赋选择治疗量、没有点无视抵抗，就要从面板补命中。毒伤生存位不能只复制英雄名，还要连天赋分支与命中一起复制。
- 该三阶段视频已进一步完成逐帧复核：`蛇女 + 斯赖特 + 图奇 + 混沌之子 + 斯特加默芬` 两战合计13.70B，技能轴为蛇女默认/18、斯赖特14.5/18、图奇14.7/18、两名生存位11.5/18。此处只证明S9构筑和轴存在，不把成绩外推给370。

### 燃烧火过渡链

S2启动骨架：

`主坦/生存 + 火拳 + 卡尔弗 + 杜瑞姆 + 机制位`

- 卡尔弗先快速堆引燃，杜瑞姆的焚毁覆盖结算窗，火拳再移除燃烧触发爆燃。
- 多目标密集站位优先；单体或目标分散时，爆燃溅射收益明显下降。
- 缺船长/杜瑞姆时可用兹拉克斯、里尔、埃尔宁等低稀有挂火/触发位过渡。当前国服技能文本与池内分类仍须370界面确认。
- 现代跨服模板常改为 `生存/增伤 + 派克西顿 + 卡尔弗 + 火拳或杜瑞姆 + 机制位`；派克西顿加入后，火拳与杜瑞姆在部分Boss互为替换，不是固定三输出捆绑。

### 旧狂野骨架

`主坦 + 治疗/减伤 + 龙妈 + 菲莉丝蒂 + 埃里奇/狂野判定手`

- 菲莉丝蒂提供旧体系的重要破防/辅助输出，龙妈承担主输出。
- 这只是能开打的旧骨架，不等于当前排行榜完整狂野；S6 火龙无法从 S1–S5 溯影获得，可拉克也需确认池内分类。
- 没有现代狂野件时，把这队定位为单体副队，不为追榜强做龙妈激励/专武。

## 4. 剧毒墓穴

历史低配骨架：

`加里乌斯/硬坦 + 埃斯特拉/治疗 + 舒克类护盾移除兼降攻 + 单体输出 + 补生存/副输出`

- 护盾处理和 2 级降攻优先于元素亲和。
- 若主坦在前两轮倒下，先调整坦克装备和治疗轴；若超时，再替换第五位为输出。
- 火/毒主 C 可以担任输出，但不应挤掉护盾移除位。
- 死亡点诊断：第一轮前倒=坦度；第1–3轮倒=治疗；第3轮后倒=清球/AOE不足。不要三种问题都用“再堆攻击”处理。
- 79级14层历史可抄样例：`埃斯特拉 + 加里乌斯 + 伊西塔瑞安 + 复制姐 + 舒克`；舒克见盾开技能，加里乌斯残血开技能，其余自动。现在只记住并保留这些工具人，不为14层提前耗尽Day1资源。
- 官方蓝紫卡教程进一步确认：磷火带减益会降低协战概率，击杀磷火会对Boss造成真实伤害，Boss二技能会复活最多两个。因此首轮至少留一组AOE处理复活怪；毒伤群攻在本关是机制适配，不等于必须上完整五毒。

## 5. 诅咒墓穴

历史 18 秒循环骨架：

`硬坦 + 敌方增益移除 + 2级降攻 + 护盾/双增益保护 + 单体输出`

时间轴基线：

- 约 6 秒：Boss 自增益后立即驱散；
- 约 12 秒：准备承受强力单体与护盾；
- 约 18 秒：在大招前覆盖护盾/防御增益，并确保降攻在场。

先手动录一次当前版本时间，再保存自动轴；不要把 2025 的 6/12/18 秒当作 370 已实测事实。

高层历史机制要求一次移除Boss两个增伤，并在Boss三技能前给全队覆盖至少两层/两种增益；只有一个驱散或只套一个盾时，增益被移除后仍会吃额外50%伤害。

79级14层历史可抄样例：`加里乌斯 + 伊西塔瑞安 + 复制姐 + 舒克 + 沃雷什`；舒克/沃雷什约250命中。高层无金辅模板：`加里乌斯 + 舒克 + 格洛弗 + 纳萨尼尔 + 阿塔尔`，因双拉条不稳定需手操。

官方机制解释补足了为什么群盾不能省：Boss只有造成生命伤害才会吸血并削减生命上限，盾让这段伤害先落在护盾上；敌增益移除负责另一条自强化链。两者不是同一职能。

## 6. 腐烂墓穴

优先从三种路线中选账号已有的一种：

1. `召唤物承受吞噬 + 坦 + 治疗 + 输出`；
2. `全体隐身躲锁定 + 净化/免疫 + 输出`；
3. `爆发队在吞噬阶段打出释放阈值`。

毒伤持续输出和龙妈单体爆发都不是万能答案。没有召唤/隐身逃课时，必须给净化、免疫或救急治疗留位置。

历史隐身实队：`冰龙/冰老头 + 冰盾/冰主 + 泰雅 + 光奶 + 冰女`。泰雅在吞噬前开全队隐身，光奶在一技能前开减益免疫；它是机制模板，不要求370照搬五人。

79级14层召唤样例：`埃斯特拉 + 加里乌斯 + 伊西塔瑞安 + 复制姐 + 叹息王`，用中间小亡灵承受先吞、两龙站左右。高层泰雅轴是Boss二技能前开启，约6秒后吞噬；10秒隐身/免疫可一起覆盖。泰雅只保护远程角色，近战火/毒主C不能直接照抄。

官方正文还给出反常识限制：Boss会按自身减益数强化一、二技能，毒伤/寒霜因此不优先；只保留禁疗、减疗、降攻等收益足够高的关键状态。燃烧是否被370版本计入同一减益数量尚未验证，不能把“火系”自动等同于安全。

## 7. 天赋领域

历史高层会压制本领域对应元素。火/毒账号进入炽焰领域高层时，准备跨元素队：

`跨元素坦 + 跨元素治疗 + 群体减益 + 2名非火毒输出`

蓝紫卡只需升到能完成机制，不要因为跨元素就再开一整套传说输出项目。

## 8. 大陆挑战赛与异界探索

建队顺序固定为：

1. 读 Boss 词条；
2. 确定生存机制与解除手段；
3. 选择能吃到词条加成的输出；
4. 先达到最低奖励档；
5. 最后才从排行榜复制高配轴。

历史上瓦妮雅菈偏好单体技能，适合狂野；塔玛尔按减益层提高受伤，适合毒伤。它们只是历史词条样例，370 实际 Boss 和数值需按当期页面重新判断。

### 现代跨赛季旁证（只用于理解队伍结构）

S8 的转载挑战指南提供了两类对火/毒很有价值的反例：

- 多目标/分身关：乔伊斯与三首领杜瑞姆允许燃烧、毒伤等群攻体系吃到多目标收益，但分别要求频繁驱散，以及驱散/免疫群体降攻；不能只堆五个输出。
- 高抵抗单体关：伊奥拉样例为 `龙妈 + 菲莉丝蒂 + 可拉克 + 索尔戈斯 + 辛纳瑞尔`，用辛纳瑞尔分享效果抵抗，再由高急速辅助维持输出环境。它说明现代狂野第五位会随 Boss 机制改变，不是永远固定埃里奇或第二副 C。

这些是S8结构证据，不是370 S1首轮Boss名单；来源目前为第三方转载，尚未找到官方原帖和完整装备页。

### 复苏之龙：2026新手赛季燃烧模板

当前可访问的新手赛季攻略给出：

`克莱索斯 + 乔恩 + 卡尔弗 + 杜瑞姆 + 派克西顿`

- 克莱索斯可换辛纳瑞尔或斯卡尔；该槽要同时处理生存、降攻、净化/驱散或团队增伤。
- 乔恩需要抵抗减充能并用技能急速给队友供能。
- 跨服起测值：四人命中大于300，杜瑞姆大于170；370按Boss抵抗、天赋共享和装备重新标定。
- 火拳未出现在这套终局燃烧队，进一步证明它与杜瑞姆/其他输出按Boss换位，而非固定必上。

## 养成优先级

`主坦生存 > 治疗/降攻能活 > 关键减益命中 > 主C伤害 > 副C伤害 > 工具人额外练度`

技能书优先给会改变循环或覆盖率的关键技能。若升级只增加少量倍率、但队伍仍死在机制点，就先不投。

火/毒/狂野的具体起测面板、共享命中条件与手动点见 [火 / 毒实战配装预设](fire-poison-build-presets.md)。其中所有数值均需按370当前Boss重新校准。
