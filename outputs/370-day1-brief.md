# 370 区 S1 Day 1 决策简报

日期：2026-10-22

当前阶段：**S1 第1天**。本文优先回答今天该做什么；14/16层装备本、异界和终局队伍只作为后续预案，不占用今天的养成资源。

2026当前规则已经确认：370先走独立新手赛季，但全服召唤日历不再按370的服务器日轮转；新区追赶/资格活动则仍需单独看370页面。今天看到S9腐蚀池并不代表370跳过了S1玩法；反过来，也不能用“开服第13天旧火毒池”预测370下一池。

## 一句话结论

今天不要因为“精选召唤 3 有 300 自选”就把资源全砸进去。官方公众号索引已确认本池 300 自选是 `卢克 / 毒龙 / 莱维尔` 三选一；你明确偏好火/毒伤且暂不想做腐蚀时，默认策略是跳过深抽、保留完整 300 抽预算。只有确认首个稀有输出保底莱维尔且愿意拿首金即停，才评估小额试抽。

更重要的是，近期新区社区记录显示“心愿召唤”开放日并不稳定：普通新服样本在开服约10天看到池；另一条明确来自364庆典服的样本估计约等一个月，还有社区回复称800档心愿是落后赛季追赶池、庆典服可能没有。常见规划为 `100 欧勾克 / 200 图奇 / 300 蛇女`。官方长图已确认六档为 `100/200/300/400/600/800`：300只到第一名稀有输出，800才拿第二名；三名英雄是玩家自选方案，不是固定赠送。370的服务器类别、开放日和候选仍待活动页核验，因此今天最优动作仍是保留300。

按370的10月22日开服日折算，先把10月31日至11月21日（Day10–30）设为心愿观察窗，而不是单点预测。论坛的“11月初天使返场”现在多了一篇10月15日霍尔法斯特投稿测评的旁证，文中称“天使本赛季再度返场”；但投稿页明确不代表官方，也没有活动日期与池规。它提升了“本赛季返场”的可能性，没有把“11月初”升级成官宣，而且昂贵灵光队与火/毒主线不闭环，仍不构成立刻转投的理由。

新增的国际服当期公告容易造成误会：它确实在10月11–19日开过六目标Wish，但370在10月22日才开服，时间上不可能参加。该公告只证明当前版本仍有“2稀有+4普通、里程碑、双稀有锁池、确认后不可改”机制，不证明370会补开。所以上面的Day10–30只是检查370新服资格页的窗口，不是承诺；今天仍按0抽腐蚀、完整保留300执行。

10月21日的S9王冠毒伤攻略又提供了非常接近你当前选择的现实对照：评论区玩家已经存300、准备等毒蛇，同时犹豫要不要在腐蚀精选捞城主；作者明确提醒精选不一定给城主。这进一步支持“不为概率普通组件打破完整300预算”。同一作者公开了两条可在370客户端测试的队伍码：有子夜 `S9261020QU5B7BX2`、无子夜 `S9261020QU7AO4B3`。它们用于预览阵容，不是区服邀请码；未导入前不假定五人和装备。

## S1 Day 1 实操清单

按顺序执行；每到锁级点再回头刷资源，避免把体力花在马上会被更高层替代的掉落上。

### 上线第一轮

- 先推主线，历史区域顺序为 `混沌荒宇 → 蓝橡树 → 安提拓姆 → 艾柏提亚 → 萌芽祭坛 → 斯塔兰 → 花蕾祭坛`；370名称或门槛若变，以任务导航为准。
- 解锁新玩法后先做一次首通/教学，领取赛季征程、主线、箱庭和妖精迷域的一次性奖励。
- 旅程商店每次刷新都检查未拥有英雄。历史官方首日文明确点名西格莉德、加里乌斯，并说明赤鸦币还可换史诗/珍稀英雄与技能卷轴；370当前商品和价格须看商店实页。
- 只养一队五人：`前排 + 治疗/护盾 + 范围减益 + 西格莉德 + 群攻/召唤输出`。历史免费样例是 `任意坦克 + 伊西塔瑞安 + 埃斯特拉 + 西格莉德 + 沃雷什`。

### 第一次锁级后

- 体力优先给能提升共鸣等级的地精据点；先手动打到当前可稳定三星的最高层，再扫荡。
- 地精优先群攻，不要带纯奶拖时间；若只差几秒，先检查自动技能是否打空、减益是否先于西格莉德、威能技是否浪费在残血波次。
- 历史实战样本约40级可挑战地精6、首日上限约59级；这是2025服进度，不是370保证值，只用于判断“地精应当优先”。
- 若下一难度已经能过，就停止刷旧难度。体力自然恢复约每10分钟1点，超上限后转入恢复更慢的储备体力；长时间离线前尽量不要让普通体力溢出。
- 地精无法三星：先补可用蓝/紫装备并手操；装备本也过不了，再回地精升共鸣。不要一次性平均抬十几名英雄。

## 精选召唤 3：条件决策树

公开名单为卢克、毒龙、莱维尔、城主等腐蚀英雄与辅助；300 抽自选候选为卢克、毒龙、莱维尔。

- **卡池可保底毒龙或卢克，且你已有另一位核心**：可以作为主池，算清到自选需要的总骰子再下。
- **只有毒龙，没有卢克**：可用于主线/部分 PVP，但腐蚀长战结算链不完整；不要用“未来也许抽到”替代预算。
- **只有卢克，没有稳定施加腐蚀的核心**：伤害燃料不足，优先补毒龙/城主，不建议单挂。
- **只有城主或雷塔**：她们是优秀组件，但不等于腐蚀队已成型；雷塔尤其可以先当通用辅助。
- **零氪/低氪且卡池无明确 300 自选**：优先停手，等能确定闭环的池。
- **偏好火/毒伤、明确不做腐蚀**：不为“自选看起来保值”而下 300；等火/毒伤旧主 C 或补强池。
- **计划冲海王/挑战赛榜**：把激励、专属神器、技能卷轴和生存位也纳入成本，不能只算抽到 0 命。

## Day 1 通用队模板

在不知道卡盒时，优先按职能组队：

`可靠前排 + 群体治疗/护盾 + 群体减益手 + 主输出 + 副输出/机制位`

常见通用思路是让群体减益手触发西格莉德的范围伤害；单体 Boss 再换成降攻、驱散、减充能与单体输出。腐蚀核心如果尚未齐，不要为了五毒亲和牺牲关键机制。

## 你的火 / 毒路线

- 开局一次性机会：先处理预言召唤3.0，再决定是否动真实日芒。3.0只到S1–S5，抽不到S7蛇女；最优作用是提前锁斯赖特、欧勾克、图奇/杜兰戈等未来蛇女队组件。详情见 [预言召唤3.0](../wiki/prediction-summon.md)。
- 默认主项目：毒伤。若心愿可选蛇女，优先走300档蛇女线；已有蛇女时，斯赖特是高价值补件但不是硬门票，杜兰戈/柯林或Boss机制位也有实队替代，不为它破坏300现金流。无蛇女时只有在现有卡盒或普通档能拿到杜兰戈/图奇至少一人时，才把 `子夜 + 斯赖特` 列为长期旧毒伤目标；若六档沿用官方模板，300只够其中一名，不能写成一次闭环。主线仍用西格莉德通用群伤队。
- 条件式第二项目：优先检查燃烧三件 `火拳 + 卡尔弗 + 杜瑞姆` 是否能在后续300档成启动骨架；现代队还常需要派克西顿及斯卡尔/欧勾克等生存增伤位，火拳与杜瑞姆也可能按Boss换位，不能把三件称作毕业。龙妈狂野只有抽到菲莉丝蒂/可拉克等核心组件，或确定能持续投入激励与专属，才提前为主项目。
- 若活动真能拿两个旧主 C：`子夜 + 龙妈` 符合喜好但属于两套队；不要在第一周同时拉满。先看组件齐度，完整的一队先升。
- 若两个都残缺：选一个喜欢的留作长期项目，另一个名额用冰龙换开荒舒适度也比养两支半成品更稳。
