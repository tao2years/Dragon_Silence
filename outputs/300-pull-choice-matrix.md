# 370 区：300 抽火 / 毒选择矩阵

Updated: 2026-10-22

## 先把三种“自选”拆开

| 入口 | 实际含义 | 300 抽能拿什么 | 与另外两种是否共用累计 |
|---|---|---|---|
| 预言召唤 3.0 | 端外反复预抽后，锁定未来日芒100抽结果 | 不消耗300抽；历史版本是锁10组十连，三金只是预抽结果 | 否；它改写日芒未来100抽，不是限时池里程碑 |
| 心愿/溯影六格池 | 先锁2名稀有输出和4名普通传说 | 官方同结构规则是100/200各拿普通传说，300拿第一名稀有输出 | 否；第二名稀有输出在800档 |
| 精选召唤Ⅲ腐蚀 | 当前全服腐蚀定向池 | 300自选卢克/毒龙/莱维尔之一 | 否；不是毒伤蛇女池，也不能指定城主 |

因此，“300抽双自选”更准确的说法是：**可预先选择两个稀有输出目标，但同模板下300只兑现第三格的一人，第二人位于第六格/800档。** S6溯影正文确认第三、六格均为稀有位，官方心愿长图与社区摘要共同支持300/800数字；如果370活动页显示不同阈值，以370页面推翻本表。

两名稀有目标还会共同限制普通候选与随机池，所以第二人不只是800档占位。预算只到300时，也要按“池子会被怎样收窄”选择，而不是随手塞一名喜欢的主C。详见[溯影双目标配对计划](retrospective-pair-plan.md)。

## 默认主线：现代毒伤

| 现有卡盒 | 100档普通传说 | 200档普通传说 | 300档稀有输出 | 300后第一补件 | 是否停手 |
|---|---|---|---|---|---|
| 四人都没有 | 欧勾克 | 图奇 | 蛇女 | 斯赖特/杜兰戈/机制位 | 停；不追800 |
| 已有欧勾克 | 图奇 | 杜兰戈/通用坦辅 | 蛇女 | 斯赖特或机制位 | 停 |
| 已有图奇 | 欧勾克 | 杜兰戈/通用坦辅 | 蛇女 | 斯赖特或机制位 | 停 |
| 已有欧勾克+图奇 | 杜兰戈 | 蕾塔或通用坦辅（须确认池内分类） | 蛇女 | 斯赖特/共享命中位 | 停 |
| 已有蛇女 | 欧勾克 | 图奇 | 斯赖特 | 杜兰戈/生存位 | 停 |
| 已有蛇女+斯赖特 | 欧勾克 | 图奇 | 不要为重复毒核硬抽；改选明确有用的第二体系主C | 生存/破防位 | 候选不优则整池跳过 |
| 已有斯赖特、无蛇女 | 欧勾克 | 图奇 | 蛇女 | 杜兰戈/生存位 | 停 |

条件：蛇女必须实际出现在370的稀有输出候选页，欧勾克和图奇必须出现在普通传说候选页。蛇女是S7英雄，不可能出现在仅覆盖S1–S5的旧溯影池；若370页面确实写S1–S5，这一整条蛇女方案不成立，应等待覆盖全英雄的独立心愿池。

### 300后可直接使用的五人骨架

`蛇女 + 图奇/杜兰戈 + 欧勾克 + 可靠前排 + 破防/降攻/驱散位`

拿到斯赖特后再改为：

`蛇女 + 斯赖特 + 图奇/杜兰戈 + 欧勾克 + 前排/破防位`

不要为了五毒亲和强拆前排或驱散。蛇女负责爆毒和削抗，图奇/杜兰戈负责铺毒，欧勾克负责不死、治疗、净化与降攻；斯赖特是高价值伤害循环补件，但2026实队已证明可按Boss由杜兰戈/柯林或额外机制位替换。

## 没有蛇女候选：旧毒伤只在能闭环时做

| 现有卡盒 | 100 | 200 | 300稀有 | 判断 |
|---|---|---|---|---|
| 已有斯赖特 | 欧勾克 | 图奇/杜兰戈 | 子夜 | 可做，300完成旧毒伤主要链条 |
| 已有子夜 | 欧勾克 | 图奇/杜兰戈 | 斯赖特 | 可做 |
| 子夜、斯赖特都没有 | 欧勾克 | 图奇/杜兰戈 | 二选一 | 300仍缺另一稀有，不算成队；除非已有稳定主队，否则不优先 |
| 连图奇/杜兰戈也没有 | 欧勾克 | 通用辅助 | 子夜/斯赖特 | 不建议立项；挂毒速度不足 |

旧毒伤的完整方向是：

`子夜 + 斯赖特 + 图奇/杜兰戈 + 欧勾克 + 生存/破防位`

社区当前版本认为蛇女已经取代子夜成为现代主链；子夜不是废卡，但不值得为了“火毒喜好”在缺少斯赖特和挂毒手时单拿。

2026年3月预抽补充篇把S7前旧毒伤稀有核心列为子夜+斯赖特，但没有列普通组件，并在当时环境下不推荐该流派。这里仅采用“双核身份”这一事实线索；其强弱判断不外推到S9。面向未来蛇女线时，优先预抽斯赖特+前向兼容普通组件，不为了补齐旧双核额外锁子夜。

## 火系第二项目：优先燃烧，龙妈是高成本项目

如果活动候选允许火拳作为300档稀有、卡尔弗与杜瑞姆作为前两档普通传说，可取得一套S2机制骨架：

| 里程碑 | 选择 | 作用 |
|---:|---|---|
| 100 | 卡尔弗 | 高频引燃、减防载体 |
| 200 | 杜瑞姆 | 焚毁增伤与副C；社区认为激励需求高 |
| 300 | 阿沙提乌斯（火拳） | 移除燃烧并触发爆燃结算 |

2026预抽社区指南也把现代燃烧识别为派克西顿、火拳、卡尔弗、杜瑞姆四件，并提醒杜瑞姆5激励的投资差异。因此白板账号若只能在300内取得火拳+卡尔弗+杜瑞姆，评分保持“可启动但未完成”，不会因为三张同流派就升级为毕业。

这是一条**条件路线**：三人的池内类别和370候选都未由客户端复核。它也不是现代毕业队。2026攻略显示派克西顿已成为重要燃烧补强，火拳与杜瑞姆在部分Boss会竞争同一输出槽，斯卡尔/欧勾克等生存增伤位也会占席。若任一人不在相应候选框，不要用相似名字或其他火卡强行替代闭环。

龙妈路线只在以下条件至少满足两项时提升优先级：

1. 预言召唤已经锁到龙妈并附带菲莉丝蒂/埃里奇等旧狂野组件；
2. 已拥有可拉克或后续现代狂野核心；
3. 愿意长期投入龙妈激励与专属神器；
4. 接受S6狂野火龙无法从S1–S5溯影获得。

否则龙妈只是长期收藏项目，不与第一周的蛇女/通用开荒队争技能书。

## 预言召唤3.0的锁码优先级

预言只看三张金还不够，要同时看原始十连位置。历史官方规则是按预抽发生顺序结算，不能自由调序；三金都在很后面的码可能需要接近100真实抽才能兑现。

| 等级 | 三金组合方向 | 使用条件 |
|---|---|---|
| S | 斯赖特 + 欧勾克 + 图奇/杜兰戈 | 为未来蛇女线一次补足伤害、生存和挂毒组件；这是多源构筑推理，不是单篇预抽帖给出的现成组合 |
| A | 火拳 + 卡尔弗 + 杜瑞姆 | S2机制骨架；三者分类须核，仍需派克西顿/生存增伤位等现代补件 |
| A | 龙妈 + 菲莉丝蒂 + 埃里奇/有效狂野件 | 接受狂野长期成本，且目标金位置靠前 |
| A | 斯赖特 + 欧勾克 + 任一高泛用坦辅 | 图奇/杜兰戈可由后续普通档补 |
| B | 单一喜欢的旧主C + 两张无关金 | 不值得为此消耗完整真实100抽；只在目标金落前20–30抽时考虑 |

锁定时记录三项：目标金所在的原始十连序号、锁定后最后目标金位置、预计真实抽数。历史社区的优化口诀“掐头去中间、金尾优先”本质是删除目标金之前和之间的空十连；370必须先确认仍沿用原序规则。

## 一眼停手规则

- 当前腐蚀精选Ⅲ：偏好毒伤/火且不做腐蚀，0抽。
- 心愿池有蛇女并且三档候选吻合：到300停。
- 心愿池没有蛇女，但已有子夜或斯赖特之一：可用300补另一名。
- 两名旧毒稀有都没有：300拿不齐，不把“半套毒伤”当成完成。
- 燃烧三件不能按100/200/300形成启动骨架：跳过；即使能取得，也先按骨架而非毕业队计价。
- 任何池子在确认结束日、候选、里程碑和累计是否独立前：不垫抽。

流派场景来自当前新手总入口仍收录的 `WIKI-030`，但表中“必须同时具备”是结合国服组件证据形成的规划判断。单卡本体强度与完整流派表现必须分开。

## 证据边界

- 官方规则事实：六格结构和100/200/300/400/600/800档，来源 `CN-OFFICIAL-013`；S1–S5溯影范围来自 `CN-OFFICIAL-008` 与 `CN-MEDIA-002`。
- 溯影交叉：`CN-MEDIA-008` 可确认第三/六阶段稀有、四个普通阶段及整池收窄；`CN-COMM-041` 仅以搜索摘要支持300/800，不作为独立定论。
- 英雄机制：蛇女/斯赖特/图奇/欧勾克由 `WIKI-004` 至 `WIKI-007` 跨版本数据库交叉；国服斯赖特与子夜联动来自 `CN-OFFICIAL-011`。
- 现代阵容反证：`WIKI-008`、`WIKI-009` 证明蛇女队可无斯赖特；`WIKI-010` 至 `WIKI-013` 证明现代燃烧存在派克西顿补强及火拳/杜瑞姆换位。
- 环境评价：现代毒伤、燃烧和狂野成本来自 `CN-COMM-035`，属于社区判断，不是官方强制结论；`CN-COMM-002`只补强S7前旧毒双核与腐蚀成本，已隔离其过时强弱判断。
- 370仍缺：活动候选页、六档奖励页和结束时间截图；在取得前，本表是条件决策树，不是已实测账号答案。
