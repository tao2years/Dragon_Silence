# 370 区溯影双目标：300 抽停手时怎么选

Updated: 2026-10-22

## 结论先说

如果 370 开的是 S1–S5 溯影池，且预算只到 300，所谓“双自选”应理解成：**先锁两名稀有输出以改变卡池范围，但里程碑只保证第三格的一名稀有；第二名要到第六格，按同模板通常是 800。**

对偏好火/毒、又计划等现代蛇女的账号，低后悔默认组合是：

`斯赖特（300优先目标） + 芙罗拉/子夜（第二目标按账号方向）`

但这不是“300必得两人”。第二目标的首要作用，是控制普通传说候选与随机池边界；只有随机提前抽到或未来追到第六格才会真正拿到。

更保守的总建议仍是：**若尚无任何旧毒稀有、也不能确认普通档能补欧勾克和图奇，整池跳过，保留300等覆盖S7蛇女的心愿池。**

## 为什么第二目标也很重要

溯影正文说明，选完两名稀有目标后：

- 第1/2/4/5阶段的普通传说只能从目标流派或对应元素辅助中选择；
- 随机出卡也会收窄到目标流派与对应元素辅助；
- 稀有输出随机结果只在所选目标内。

所以第二目标即使800前拿不到，也会影响前300抽的“池子污染度”。它不是无意义占位。

## 三种火/毒配对

| 稀有双目标 | 300停止时的价值 | 池子倾向 | 主要风险 | 适合谁 |
|---|---|---|---|---|
| 斯赖特 + 子夜 | 旧毒组件密度最高；两人任一提前随机出都能缩短成队距离 | 毒伤 + 毒元素辅助，范围相对集中 | 只保底一名时仍缺另一旧毒核；蛇女到来后子夜长期价值下降 | 已有子夜或斯赖特之一；或确定长期玩旧毒 |
| 斯赖特 + 芙罗拉 | 斯赖特可桥接未来蛇女；同时让火/狂野相关组件进入候选 | 毒伤 + 狂野，兼容火/毒偏好但池面更宽 | 300不会自动完成任何一整队；龙妈高激励/专武/现代组件成本高 | 明确把斯赖特放第一，龙妈只作长期收藏/第二项目 |
| 子夜 + 芙罗拉 | 两个喜欢的古早主C都进池 | 旧毒 + 狂野，方向最分散 | 缺斯赖特时旧毒不闭环，龙妈也缺狂野件；最容易“两个半队” | 只适合已有两边关键组件的老卡盒，不适合白板新区 |

## 组件选择顺序

若选择含毒伤目标，前300的普通档优先：

1. `欧勾克`：不死、治疗、净化、降攻，兼具泛用性；
2. `图奇`：高频多段挂毒，能立即服务旧毒，也能衔接未来蛇女；
3. 已有其中一人时再看 `杜兰戈`、可靠坦克、破防或副本机制位；
4. 不要为了凑五毒亲和而放弃前排、驱散和减攻。

若选择芙罗拉，普通档只有在能形成狂野发动链时才拿纯狂野输出；白板新区更应优先火元素泛用辅助或能跨副本使用的生存位。龙妈本体、两张零散狂野件和低激励并不等于可直接打高层。

## 抽前四个硬检查

1. 活动正文是否写 S1–S5，还是覆盖全赛季；
2. 六档数字是否确为 100 / 200 / 300 / 400 / 600 / 800；
3. 第三格究竟绑定哪名稀有目标，能否在确认前交换顺序；
4. 普通候选页是否真的出现欧勾克、图奇及你要的火系组件。

任一项不清楚就先不抽。随机提前出第二稀有是好运，不纳入预算承诺。

## 证据边界

- S6二手全文可确认第三/六阶段是稀有、其余四阶段是普通，且整池按目标流派/元素收窄；来源 `CN-MEDIA-002`、`CN-MEDIA-008`。
- 官方心愿长图确认同类六格数值为100/200/300/400/600/800；来源 `CN-OFFICIAL-013`。
- 巴哈搜索摘要也把300/800称作稀有档，但正文403不可访问，仅作社区交叉线索；来源 `CN-COMM-041`。
- 370目前没有游戏内截图，所以“溯影阈值完全照搬心愿”和“第三格可按任意顺序指定”仍是待验证项。
