# 370区S1 Day 1–7战斗手册

Updated: 2026-10-22

## 使用边界

2026-09的当前Beginner Guides总页仍把下列S1攻略列为新手入口，因此可用其机制、职能与手操点设计370试战方案。子页主体写于2025-06，故等级上限、赠送英雄、装备开放日和保底数字不是370事实；370界面不同就以实测覆盖。

## Day 1：按这个顺序推进

| 顺序 | 做什么 | 停手条件 | 阵容/操作重点 |
|---:|---|---|---|
| 1 | 主线推进 | 自然锁级或战力硬墙 | 一坦一奶、主群攻、西格莉德、群体减益；先拿Furywood Claws |
| 2 | 地精逐层首通 | 无法三星/无法继续 | 不在低层反复刷；六波按2人/3人两组威能轮转 |
| 3 | 剧毒墓穴逐层首通 | 坦被秒或无法及时清小怪 | 群攻+群体降攻+奶；先吃首通，不追完美装 |
| 4 | 回地精重试 | 当前装备仍过不了 | 新装备给主C/群攻位，手操轮转 |
| 5 | 主线卡点/探索资源 | 能拿一次性资源就拿 | 卡The Blasphemous先查禁疗和减伤轴，不盲升冷门卡 |
| 6 | 时空涡流/海王 | 下线前打出当日最高单次 | 单体输出、降攻、破防、生存；最后再打以吃等级/装备提升 |
| 7 | 日常收尾 | 活跃、盟会、竞技、迷域、红点清完 | 记录层数、失败点、橙骰和卡盒 |

历史攻略建议只有能稳定刷地精Lv.6时才反复投入体力，否则优先探索、NPC挑战、先祖遗迹和一次性天赋石。Lv.6不是370硬门槛，但“先首通、少刷低收益层”的资源原则成立。

## 地精1–6：五人和手操轴

历史免费/低配模板：

`拉瓦（Rava） + 维迪米尔（Vidimir） + 罗薇娜（Rowena） + 沃雷什（Voresh） + 西格莉德（Sigrid）`

六波循环：

1. 第一波用两名英雄的威能清；
2. 第二波用另三名清；
3. 第三波回到第一组，如此交替，避免同一波五个全交；
4. 沃雷什先开群体减益，西格莉德后开，利用她对带减益目标的范围追击；
5. 拉瓦先完成前置后，维迪米尔和罗薇娜再开。

替换原则：不强求这五人；任何“稳定群体减益 → 西格莉德范围收割”都能替代。若一组两人清不掉，就把当前最强群攻放进两人组，把辅助/残血收割放三人组。

## 剧毒墓穴：Day 1装备起点

### 1–8层

`主坦 + 治疗 + 群体降攻/减益 + 两个群攻`

- 杀小怪会对Boss造成真伤，群攻价值高；
- 小怪带减益时协击概率降低；
- 生存压力低时可把第二生存位换输出。

### 9–14层预案

`主坦 + 群体降攻 + 治疗 + 减伤/第二治疗 + 主输出`

- 群体降攻要覆盖Boss与小怪；
- 坦仍被秒时，不要继续堆第三输出；改双奶或减伤+奶；
- Day 1只保留对应工具人，不提前为14层重投入。

## 三类天赋本1–6

| 本 | 克制元素 | 低配核心 | 手操节点 |
|---|---|---|---|
| 火毒素材本 Wildfire | 火/毒 | Catherine免疫；Garius自净；Ladehlia+Isitarian召唤清场 | 第二阶段留Catherine，进第三阶段前开免疫，挡燃烧 |
| 电光素材本 Resplendence | 电/光 | Estella+Heksandra双奶；Frurbath；Sigrid清幼龙 | Boss第二小阶段前关自动，进场集中开；幼龙先挂减益再让Sigrid清 |
| 冰暗素材本 Permafrost | 冰/暗 | Catherine/Acilia免控；Shook驱盾；Vani替补 | Exhaustion或降攻存在时不开威能；等Boss第二技能后再开，Boss威能前免控 |

关键理解：素材本会克制正在刷的那一对元素。喜欢火/毒不代表拿火毒主队硬撞火毒本；首周必须保留跨元素免疫、净化和群攻工具人。

## Day 1海王：先拿档位，再谈流派上限

低配基线：

`贝里克/加雷斯 + 海桑德拉/加里乌斯 + 戴因/埃斯特拉 + 两个当前最强单体输出`

必须检查：

1. 穿完装备后，主坦生命值严格为全队最高；历史雷电之召会锁最高生命目标；
2. 初次用 `1坦+2辅助+2输出`，坦死就把一个输出换第二治疗/减伤；
3. 贝里克有减伤、二级降攻与自恢复，加雷斯也有二级降攻；
4. 海桑德拉偏群体瞬抬，加里乌斯堆防御后群回，埃斯特拉偏保单坦；
5. 戴因给目标防御，大招提供减伤与保护；
6. Boss越打越痛，降充能/偷威能/降威能属于后续减压工具；
7. 今天最后一轮再打，让白天获得的等级、装备和技能全部计入当日最高伤害。

当前新手入口的S1介绍称早期Boss伤害较低，可尝试四名同阵营输出/辅助吃亲和、第五格跨元素治疗；但370火/毒白板不为凑亲和拆掉必要降攻与治疗。龙妈四狂野和蛇女毒伤都是中后期上限路线，不是Day 1合格线。

## 主线卡点一：The Blasphemous

历史低配五人：

`Garius + Sigrid + Thia + Ihuicatl + Estella`

职责不是固定人名：

- 前排：抗6–17秒连续攻击和控制；
- 两个禁疗位轮转，阻止Boss每次技能后的回血；
- 二级防御提升/护盾挡威能爆发；
- 快速治疗拉回血线；
- Sigrid同时承担降攻和禁疗。

18秒循环试战轴：

1. 0–5秒保留关键技能；
2. 6–17秒前排进入多段+控制窗口，历史方案用Light Spear和三件Tidal Force抗控制；
3. 两名禁疗位错开覆盖，不要同时开；
4. Boss威能前依次开Sigrid降攻、Ihuicatl盾/二级防御、Estella治疗；
5. Thia不用盲堆急速，过早开会与另一禁疗重叠；
6. 两三轮后仍因面板崩盘，等第二日削弱宝石/等级，不把卷轴砸给临时卡。

## 主线卡点二：Ooze Monster

一眼越级历史模板：

`Vicuc + Ihuicatl + Garius + Estella + Tonalnan`

- Vicuc：群体净化两个减益+二级降攻；
- Ihuicatl：队友开威能时给盾，与降攻形成循环；
- Garius+Estella：低血线恢复；
- Tonalnan：不依赖完整狂野体系的单体输出。

Boss三种技能都会叠毒，顺序应是：

`净化/免疫 → 降攻或防御提升 → 护盾/治疗 → 单体输出`

同类一级/二级增减益不要重叠浪费。看到当前防御提升仍在，就等它结束后再接下一段；这场时间宽松，生存优先于抢伤害。

## Day 2–7投资节奏

| 日段 | 目标 | 不做什么 |
|---|---|---|
| Day2–3 | 若获得Garius可换Horrus；先主坦/主C套装，再回地精；Furywood Claws给主C | 不给全队平均强化；不把历史59级当370上限 |
| Day4 | 历史节点为60级、金装、正向符文；370按实际开放 | 不为套装效果牺牲关键命中/急速/生命 |
| Day5–6 | 主C和主坦对应天赋先4；火毒/冰暗/电光成对刷 | 不拿被克制主队硬刷本；保留跨元素工具人 |
| Day7 | 全队基础装备与天赋齐后再精调主坦/主C | 不同时养第二支残缺流派 |

## 370每次失败只记录四件事

1. 失败发生在Boss第几秒、哪一个技能；
2. 是坦先死、全队爆死、超时还是机制失败；
3. 当时降攻、免疫、盾/防御提升是否覆盖；
4. 换人或调轴后结果。

这四项足以判断是“等级/装备墙”还是“阵容/技能轴错”，比只发五个头像更有用。
