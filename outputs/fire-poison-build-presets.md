# 370 区火 / 毒实战配装预设

Updated: 2026-10-22

这不是“照着堆就毕业”的面板表，而是从 2026 跨服实队中提炼出的起测预设。370 目前是 S1 Day 1，先保存逻辑；拿到实际 Boss、装备和卡盒后再校准数字。

## 先判断你处在哪一种命中模型

| 模型 | 怎么识别 | 配装动作 |
|---|---|---|
| 无共享命中 | 队伍没有明确写着把自身命中分享给队友的装备/技能 | 每个关键挂毒、破防、点火和减益位单独满足 Boss 命中线 |
| 有共享命中 | 卡拉维拉、派克西顿等明确携带共享命中配置，且效果已经激活 | 共享者堆极高命中，其他人降到攻略起测线；换掉共享者后全队立刻重配 |
| 特殊状态上限 | Boss 限制可保留的增益/减益数量，或后施加会覆盖先施加 | 先保降攻、破防、关键毒/燃烧；删除低价值减益，不按“减益越多越强”配队 |

370 实测时只改一项：先固定队伍与技能轴，逐级降低命中，连续三次无抵抗才记为当前最低稳定线。

## 预设 P1：300 抽蛇女启动队

`独立前排 + 蛇女 + 图奇 + 欧勾克 + 破防/净化/机制位`

- 蛇女：先满足关键削抗/爆毒机制需要，再堆启迪与输出；当前国服数值待界面。
- 图奇：技能急速优先于盲目堆面板攻击，多段挂毒频率决定蛇女发动次数。
- 欧勾克：先生存和覆盖，再补治疗相关属性；需要降攻命中时单独达线。
- 第五位：按 Boss 选破防、净化、驱散或第二生存位。不要为了“五毒”拿掉必需机制。
- 没有斯赖特也能开工；已复核的现代高配存在 `蛇女 + 杜兰戈 + 图奇 + 蕾塔 + 欧勾克`。

## 预设 P2：现代毒伤，无共享命中

`蛇女 + 斯赖特/杜兰戈/柯林 + 图奇 + 生存位 + 机制位`

- 图奇、斯赖特：优先从符文副属性堆技能急速，让挂毒/猛药频率先稳定。
- 每个关键减益位独立过命中线；不能借用“队友只需 130”的共享配置结论。
- 斯赖特不是硬门票：无斯赖特用杜兰戈或柯林，腾出的资源优先保证蛇女、挂毒与生存。
- 特殊 Boss 若最多保留四个状态，先排好 `降攻/破防/核心毒/机制减益` 的保留顺序，防止后施加的低价值状态覆盖破防。

## 预设 P3：现代毒伤，共享命中

跨服样例：`蛇女 + 斯赖特 + 图奇 + 卡拉维拉 + 纳萨尼尔`

| 角色 | 跨服起测值 | 作用 |
|---|---:|---|
| 卡拉维拉 | 命中 >450；技能急速 >40 | 携带 Bone Resonance，共享命中并承担防御/机制 |
| 其他毒伤位 | 命中 >130 | 仅在上述共享效果实际生效时成立 |
| 纳萨尼尔 | 技能急速 >60，之后生命 | 生存与循环 |
| 图奇、斯赖特 | 符文副属性继续堆技能急速 | 提高挂毒与猛药频率 |

把卡拉维拉换掉、共享效果未激活或 370 装备文本不同，`>130` 立即作废。

## 预设 P4：S9三阶段长战生存双辅样本

公开视频逐帧复核队伍：`蛇女 + 斯赖特 + 图奇 + 混沌之子 + 斯特加默芬`。

| 角色 | 视频起测值 | 首次/再次威能 |
|---|---:|---:|
| 蛇女 | 命中65、精通362、急速11 | 默认 / 18.0秒 |
| 斯赖特 | 命中77、精通304、急速44 | 14.5 / 18.0秒 |
| 图奇 | 命中114、抵抗62、精通142 | 14.7 / 18.0秒 |
| 混沌之子 | 命中174、抵抗82、生命+64009 | 11.5 / 18.0秒 |
| 斯特加默芬 | 命中164、抵抗52、防御+1553 | 11.5 / 18.0秒 |

该样本的价值不是让370照抄数字，而是说明同队五人的命中线按技能职责分开：两个生存/机制位反而高于三个毒伤输出。两战合计13.70B依赖S9关卡、79级装备、图奇/斯特加默芬5激励与混沌之子2激励，不能当新区目标线。

## 预设 P5：S9四阶段高投入蛇女 + 蕾塔

`蛇女 + 图奇 + 斯赖特 + 混沌之子 + 蕾塔`

- 蛇女/图奇/斯赖特命中分别约60/281/182；两个生存机制位混沌之子/蕾塔反而约270/264。
- 首次轴：蛇女默认、图奇14.5、斯赖特14.2、混沌之子11.5、蕾塔14.0；之后统一18秒。
- 两战合计21.95B，但投入是蛇女4、图奇5、混沌1、蕾塔4激励。它只能当终局参考，不能用来论证370首周应追蕾塔激励。

## 预设 P6：王冠上路有/无子夜对照

| 版本 | 五人 | 录制成绩 | 关键轴 |
|---|---|---:|---|
| 无子夜/图奇 | 蛇女、斯赖特、混沌之子、城主、图奇 | 3.85B | 10.0 / 11.7 / 默认 / 11.5 / 11.8，之后18秒 |
| 有子夜 | 子夜、蛇女、斯赖特、混沌之子、城主 | 3.35B | 11.7 / 10.0 / 11.6 / 默认 / 11.5，之后18秒；混沌之子保持默认 |

同账号同Boss的图奇版高约14.8%，但每套只看到一次结算，不能当作跨Boss结论。对370的意义只是：若300预算只能先完成蛇女+图奇，不必因缺子夜停建。

## 预设 F1：现代燃烧，无共享命中

跨服样例：`欧勾克 + 托维尔 + 派克西顿 + 杜瑞姆 + 卡尔弗`

| 角色 | 跨服起测值 |
|---|---|
| 杜瑞姆 | 命中 >160，并补一定抵抗 |
| 派克西顿 | 启迪 >400、命中 >160、抵抗 >200 |
| 卡尔弗 | 命中 >290、抵抗 >200 |
| 欧勾克 | 命中 >220、抵抗 >400、技能急速 >100 |
| 托维尔 | 命中 >290、抵抗 >250、技能急速 >70 |

有派克西顿时，部分 Boss 可把杜瑞姆换成火拳；没有派克西顿可用比格斯。数字差异本身说明：命中取决于 Boss 与队内共享机制，不要把卡尔弗 `>290` 写成所有副本固定线。

## 预设 F2：现代燃烧，共享命中

跨服样例：`玛舒图尔 + 杜瑞姆 + 派克西顿 + 卡尔弗 + 狄尔基`

| 角色 | 跨服起测值/轴 |
|---|---|
| 派克西顿 | 共享命中配置，命中 >400 |
| 杜瑞姆、卡尔弗 | 命中 >170；前提是共享配置生效 |
| 玛舒图尔 | 命中 >250、技能急速 >60 |
| 狄尔基 | 暴击率 100%、启迪约 400 |
| 杜瑞姆 | 保持全队最高攻击 |

站位还能规避该 Boss 的部分技能。五亲和后，原攻略可用兹拉克斯、比格斯替换玛舒图尔、狄尔基；370只把它当替换思路，不当英雄强度定论。

## 预设 F3：新手季 Day 54 复苏之龙终局目标

`克莱索斯 + 乔恩 + 卡尔弗 + 杜瑞姆 + 派克西顿`

- 克莱索斯、派克西顿、卡尔弗、乔恩：跨服起测命中 `>300`。
- 乔恩：抵抗 `>300`，之后继续堆技能急速，避免减充能并给队友供能。
- 杜瑞姆：命中 `>170`。
- 克莱索斯可换辛纳瑞尔或斯卡尔；替换槽必须继续处理生存、减益与团队增益，不能只看输出。
- 这是一套 Day 54 长线目标，不是 Day 1 资源门槛。当前先保留乔恩类供能/抵抗辅助和卡尔弗类点火位。

## 预设 W：若最终选择龙妈

现代狂野有两类不同起测法：

1. `辛纳瑞尔 + 龙妈 + 可拉克 + 卡斯帕 + 菲莉丝蒂`：辛纳瑞尔抵抗 `>450`；其余核心抵抗 `>270`；菲莉丝蒂命中 `>290`、暴击率 100%；可拉克启迪 `>400`。在 Boss 第五技能前，辛纳瑞尔手动把威能给龙妈。
2. `龙妈 + 菲莉丝蒂 + 可拉克 + 索尔戈斯 + 斯卡尔`：斯卡尔、索尔戈斯抵抗 `>300`并重点堆生命/防御；斯卡尔激励 1 时另需命中 `>290`；菲莉丝蒂命中 `>290`、暴击率 100%；可拉克启迪约 `400`。

另一个大陆挑战样例要求索尔戈斯/辛纳瑞尔尽量堆急速，菲莉丝蒂 `>290` 命中；索尔戈斯激励至少 2 时手动每轮双威能。它进一步证明龙妈队的辅助、抵抗和手操要求随 Boss 改变，不能只收集三个狂野输出。

## Day 1 现在怎么用

1. 腐蚀精选Ⅲ继续 0 抽，以上预设不改变现金流决策。
2. 装备只锁定有潜力的命中、急速、抵抗、启迪副属性，不为未来角色提前强化到满。
3. 保存两套毒伤配置：海王长战的低/零命中柯林；短副本的急速+命中柯林，禁止混用。
4. 每次失败只记录一个主因：抵抗、死亡、循环错位、超时或状态被覆盖。
5. 取得 370 Boss 文本后，把本页数字复制到实测表作为“起点”，而不是“答案”。
