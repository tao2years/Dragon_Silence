## Day 1可直接执行的历史清单

2025官方首日整合帖给出的推进顺序为：`混沌荒宇 → 蓝橡树 → 安提拓姆 → 艾柏提亚 → 萌芽祭坛 → 斯塔兰 → 花蕾祭坛`，并解锁破败商道、聆风之森、落星原郊野三处箱庭。370若主线命名/锁级相同，可按此检查漏项；若不同，只保留“主线推到锁级再回刷”的原则。

2026-09当前新手指南总入口仍收录的七日成长正文给出了更精确的首日战斗顺序：`主线到Furywood Claws → 地精逐层首通到墙 → 剧毒墓穴逐层首通到墙 → 回地精重试 → 装备无法再提升后用最新练度打海王`。不反复刷低收益地精层；正文历史建议能稳定Lv.6再刷，370把Lv.6仅作起测参考。

- 免费职能队历史样例：`任意坦克 + 伊西塔瑞安 + 埃斯特拉 + 西格莉德 + 沃雷什`。它证明开荒无需先抽派系主C，不代表五人必须照抄。
- 赤鸦币旅程商店历史上会每日刷新未拥有史诗/珍稀英雄，西格莉德、加里乌斯是官方点名的高价值目标；同时检查技能卷轴，先别把赤鸦币花在可替代杂项。
- 地精先用范围输出；推主线到当前上限后再投入体力，差一点超时时先查自动空大与手动威能，而不是立刻换流派。
- 落星原郊野赤鸦商人历史上出售稀有钥匙；遇到地图交易员先检查地图/钥匙类一次性物品。
- 历史首周曾有每日800龙髓石换10抽、前期30次技能重置；370必须看商店和重置页是否仍存在，不能把旧福利计入预算后才去找入口。
- 30/50级突破失败后历史上会扩大增益选择；优先复试并加生存，不要为一次失败平均升级十几名英雄。
- 历史首日收尾为：活跃100点、用最新练度重打时空涡流、大角斗场10次免费挑战、全域竞技门票防溢出、妖精迷域推到可稳定层数。370若计数不同，以当日界面为准。
- 历史第二日签到会给瓦斯卡与拉德丽娅，并可向召唤流过渡；370若奖励改版，不为等旧签到角色耽误今天的通用五人。

## 每阶段通过条件

### Day 1–3

- 主线不因平均养卡而卡级；免费/低稀有队可稳定过日常。
- 已进入一个有活跃人数和明确盟会战计划的盟会。
- 已记录世界日历第一页，确认海王、时砂和首次结算的真实日期。

### Day 4–14

- 地精：至少一套范围减益 → 西格莉德触发 → 收尾的自动轴。
- 毒墓：坦克硬度、攻击降低、治疗/护盾解除齐全。
- 诅咒墓：能在历史 6/12/18 秒节点安排驱散、降攻与护盾；若当前技能轴不同则重新录像计时。
- 腐烂墓：至少有一次净化/免疫和救急爆发，能处理召唤物与隐身压力。

### Day 15–36

- 主队 5 人稳定，额外工具人达到 6–8 名；“工具人”只升到能活着完成机制。
- 溯影六格在确认界面后锁定；未确认普通传说分类前不提交选择。
- 海王记录至少三次：阵容、装备、技能时点、伤害与死亡时间。一次高分不算稳定。

### Day 37–70

- 每个高难 Boss 先定生存机制和最低奖励档，再决定是否投入主 C。
- 排行榜只用于发现阵容结构；必须同时核对激励、专武、神器、站位和战斗时长。
- 终局前保留一套可跨队使用的坦/奶/降攻/驱散/免疫组件，避免六支纯输出残队。
- 火系若准备复苏之龙，提前测试减益清除、抵抗和威能供给；跨服攻略的300/170命中只作起测参考，不当370硬阈值。

## 370 区应立即截图的四页

1. 世界日历全页；
2. 海王 Boss 技能与奖励档；
3. 溯影召唤六阶段奖励和全部候选；
4. 当前英雄卡盒按“传说/史诗/珍稀”筛选后的页面。

这四页能够把历史路线换成 370 区精确日期，并生成逐副本可抄阵容。
