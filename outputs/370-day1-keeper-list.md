# 370 区 Day 1：英雄保留与投资清单

Updated: 2026-10-22

本表回答两个不同问题：**今天升谁**，以及**哪些蓝紫工具人以后会用、今天不要乱投技能书**。历史副本名单只证明职能价值，不代表370当前数值完全相同。

## A档：今天五人主队里有位置就养

| 职能 | 优先角色/方向 | 今天投入 |
|---|---|---|
| 范围触发核心 | 西格莉德 | 等级、可用装备；技能书只在确实提高循环时投入 |
| 范围减益 | 沃雷什或任一稳定群体减益手 | 保证命中后再堆伤害 |
| 前排 | 加里乌斯/费尔巴斯/当前最硬坦 | 生命、防御和关键减伤优先 |
| 治疗/护盾 | 埃斯特拉、海桑德拉或当前最稳定群奶 | 先保证能活过第二轮威能 |
| 群攻/召唤 | 伊西塔瑞安或当前覆盖最多目标的输出 | 地精与主线使用，单体火毒核不强行替代 |

五人结构是：`前排 + 治疗/护盾 + 范围减益 + 西格莉德 + 群攻/召唤输出`。若某名传说卡不能填这五个职能，Day 1 不因为稀有度更高就强塞。

B档的原则是“留着，不立刻养”。Day 1 不为未来14/16层提前消耗共鸣经验、传说技能书或专属资源。

## 今天不要做的事

- 不把传说稀有度当作唯一上场标准；副本机制卡常由蓝紫卡完成。
- 不给所有“以后有用”的工具人同步升级。
- 不为五元素亲和撤掉唯一驱散、降攻、护盾或治疗。
- 不把历史攻略的250命中、18秒轴和14层阵容当成Day 1硬指标。
- 不在腐蚀精选Ⅲ垫抽来补普通工具人；精选不保证指定城主或辅助。

## 升级触发器

只有出现下列失败证据才从B档拉人：

1. Boss护盾导致超时 → 舒克/破盾位；
2. Boss持续增益叠高 → 格洛弗、丹或多目标驱散；
3. 主坦前两轮倒 → 降攻、护盾、坦装，而非先换更多输出；
4. Boss回血 → 禁疗；
5. 全队被减益压垮 → 净化/免疫；
6. 腐烂吞噬无法处理 → 泰雅隐身或召唤物承吞路线；
7. 机制已解决仍超时 → 再拉主C/副C伤害。
