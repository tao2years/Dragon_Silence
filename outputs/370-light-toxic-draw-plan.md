# 370区灵光 / 毒伤双路线抽卡规划

更新：2026-10-23

## 结论先行

当前账号不是“毒伤待建”，而是“毒伤已成型、缺斯赖特抬上限”：已确认拥有蛇女、图奇、杜兰戈、蕾塔、欧勾克、城主和泥魔；`蛇女+图奇+城主+蕾塔+泥魔`已在370海王存活到结束。灵光则没有已确认核心卡盒，属于从零建设第二体系。

因此抽卡顺序应是：

1. 当前腐蚀精选Ⅲ继续0抽；腐蚀不等于毒伤。
2. 若370当前溯影页确认斯赖特可选、第三格确为300档，优先用300取得斯赖特；不要再按旧模板重复选欧勾克、图奇、蛇女。
3. 灵光只作为第二项目。只有自选池能同时给出灵光主C和至少两名关键普通组件，或账号本身已抽到这些组件，才进入投入阶段。
4. 即使11月出现天使专属池，没有灵光主C和完整组件壳也默认跳过；“天使强”不等于“单抽天使就有灵光队”。
5. 任何精选、定向、专属、溯影、心愿的累计默认相互独立；不在腐蚀池或天使池垫抽等待继承。

## 为什么现在毒伤优先

| 位置 | 当前状态 | 作用 |
|---|---|---|
| 蛇女 | 已有 | 爆毒发动机、削抗、精通成长 |
| 图奇 | 已有 | 高频挂毒、副C |
| 杜兰戈 | 已有 | 命中光环、多段挂毒、斯赖特替代位 |
| 城主 | 已有 | 毒素易伤、共享与机制位 |
| 蕾塔 | 已有 | 降攻、净化、防御与减益延长 |
| 欧勾克 / 泥魔 | 已有 | 不死、治疗、净化、降攻或前排 |
| 斯赖特 | 缺 | 猛药、多段挂毒和毒伤上限 |

毒伤只缺一张高价值上限件；灵光则至少还要确认主C、能量/增伤组件、保护位和专属池角色。单看流派强度而忽略建队距离，会把“一张斯赖特补完现队”错误换成“几百抽得到半套灵光”。

S7社区长帖也明确警告，没有大天使的新区直接做光龙成本很高；这是社区意见，不是官方禁令，但与当前账号的组件缺口一致。

## 按预算执行

### 只有300抽：强化毒伤

若溯影/心愿页面满足以下条件：

- 斯赖特在稀有输出候选；
- 第一个稀有奖励确实在300；
- 可以指定斯赖特为第一个稀有奖励；
- 前两名普通奖励不必重复选择已有角色；

则300档优先斯赖特。100/200档先选账号缺少、能跨副本使用的生存/盾/驱散位；若候选里存在灵光关键普通组件，也可拿其中两名作为第二项目种子，但不能把它们当成已经建成灵光队。

到300立即停。现有毒队可从杜兰戈版测试切换到斯赖特版；换人时记录失去的命中光环、暴击挂毒和生存，不能只比较结算总伤害。

### 600抽：默认仍在300停

400和600通常仍是普通传说档，不是第二名稀有主C。只有以下三项同时成立才继续：

1. 两个普通档都是灵光不可替代组件，而非泛用替代卡；
2. 已有或已确定能取得灵光主C；
3. 抽到600后仍保留下一次核心池/专属池的保证预算。

否则600是为两个普通角色多付300抽，性价比低于等待后续定向或歪出。

### 800抽：可以规划毒伤+灵光双体系

若确实准备一轮投入800，需要根据目标排序：

- **即时强度优先**：300斯赖特，800灵光主C。先补完已成型毒队，灵光延后。
- **多队宽度优先**：只有100/200/400/600能组成灵光四人壳时，才考虑300灵光主C、800斯赖特；毒伤在此期间继续用杜兰戈/图奇版本。

第二方案必须看到候选页后才能落名。当前只确认社区常见灵光构筑需要光龙、蝴蝶、林科斯/同类能量组件、天使或保护位；这些昵称与候选分类尚未用370页面核验。

## 天使 / 灵光专属池怎么处理

官方历史只确认弥菈希亚“圣谕辉光召唤”在2026-06-26和08-17出现过，证明专属池会返场；两次相隔52天，不能推出11月8日。11月8日目前只是社区具体日期。

若正式官宣天使池，先检查：

1. 是角色专属池、精选池还是阶段奖励池；
2. 保底/累计是多少，是否独立清零；
3. 天使本体、激励和专武分别需要多少预算；
4. 账号是否已有灵光主C以及至少两名能量/增伤组件；
5. 抽后是否仍保留斯赖特或下一核心池预算。

当前账号在第4项尚未通过，所以默认动作是跳过。若此后先取得灵光主C与组件，再重算，不把“返场必拿”的老玩家意见照搬到新号。

## 后续轮转推测

全服S9与370新区是两条并行时间线。

### 全服S9

已知三轮新输出精选为暗影、灵光、腐蚀，三名S9新输出已分别落池。因此下一轮相对更可能是：

| 候选事件 | 相对判断 | 观察窗口 | 账号动作 |
|---|---|---|---|
| 辅助定向 / 流派自选 / 溯影类 | 中等，结构上高于再来新输出精选 | 10月31日–11月6日，延长观察至11月8日 | 只有300内补成完整职能链才抽 |
| 天使专属返场 | 中低；有历史返场，但本季日期仅社区线索 | 社区指向11月8日 | 当前灵光空壳默认跳过 |
| 精选召唤Ⅳ新输出 | 低，但不能排除 | 当前精选结束后 | 看实际流派与候选，不按“Ⅳ”字样下注 |
| 空窗或其他活动 | 不能排除 | 任意 | 继续存骰 |

10月31日来自S7“最后精选后9天转自选”的历史样本，11月6日来自S8的15天样本；11月8日是独立的社区天使日期。这些日期只决定提高检查频率，不构成开池承诺。

### 370新区

新区心愿/追赶池观察窗为Day10–30，即10月31日至11月21日。它可能与全服下一池同时存在，也可能因服务器类型而不出现。

因为账号已经有蛇女、欧勾克和图奇，若370心愿出现，旧的`100欧勾克→200图奇→300蛇女`方案作废。新方案是：

- 300稀有优先斯赖特；
- 100/200选择不重复的关键生存/机制位，或经过候选页确认的灵光组件；
- 第二稀有目标可用来收窄池面，但800前不承诺取得；
- 若斯赖特不在候选或第三格不是300，暂停，不硬抽。
